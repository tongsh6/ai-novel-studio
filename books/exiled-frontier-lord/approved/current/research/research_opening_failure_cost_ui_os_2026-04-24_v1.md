## 结论先行

`v12` 的核心不是继续把前三章写得更顺，而是把“顺”打破：莱恩必须失手、误判、付代价、硬撑；星火疆图必须从“攻略器”降级为“局部事实仪表”；内心 OS 必须从高频翻译器降级为少量压力反应；配角必须从响应主角改为带着私欲和恐惧主动行动；世界感必须靠历法、帝国文书、教会印记、火种塔、界碑残件等物件轻量嵌入，而不是解释。

`v12` 应保留 `v11` 已修好的三点：旧库到冬厅的因果、人物声音分叉、事件前因后果。但 `v11` 仍可能给读者“莱恩一直判断正确、所有人很快归位、危机被流程化解决”的观感。下一版必须让读者看见：他会算账，但账会算错；他能立规矩，但有人真的敢踩线；他有金手指，但金手指只照亮一小块地，剩下的黑处要靠人命和代价去探。

## 设定冲突与风险标记

### 冲突 1：ch02 提前引爆尸铃袭击 vs 正式合同禁止过早大型战斗

- 来源事实：`contract_ch02_v1.md` 明确写有“不要过早引爆大型战斗”。
- 作者最新批评：第二章提前引爆尸铃袭击。
- 分析判断：二者可以部分兼容，但必须把 ch02 的尸铃处理成“局部贴脸袭击/梦行/井边污染触发”，不能写成完整夜喉围攻或大型战斗。
- 对本书建议：`v12 ch02` 写“尸铃点名导致一名领民/孩子/罗维梦行冲井，井边爆发短促袭击，消耗粗盐、火油和一名伤员”，章末留下未解决余波；真正的组织性守防和立规代价放到 ch03。

### 风险 2：过度削弱星火疆图会丢失经营爽点

- 来源事实：星火疆图正式功能包括显示地图、资源、污染、人口、治安与灾厄趋势，并能提供建筑蓝图与生产链建议。
- 分析判断：作者批评的是“攻略器感”，不是要取消可视化经营爽点。
- 对本书建议：前三章只允许显示“局部事实 + 不完整状态 + 可用资源清单 + 风险趋势”，不显示任务、奖励、路线、完整蓝图。建筑蓝图可以等 ch03 结尾或 ch04 再以残缺图纸形式出现。

### 风险 3：OS 降频后可能重新变冷

- 来源事实：前序候选研究曾为解决远距离叙事而增加 OS。
- 分析判断：本轮要降的是公式化频率，不是完全删除人物近感。
- 对本书建议：每章保留少量“压力反应”和“自我校正”，让读者知道莱恩不是机器，但所有 OS 必须短、贴动作、带代价。

### 风险 4：历法尚未正式细化

- 来源事实：正式层已有曜辉帝国、圣火教会、火种塔、界碑等要素，但未见已批准的具体历法名称和年月体系。
- 分析判断：直接固定“某某历某年某月”会新增候选设定。
- 对本书建议：`v12` 可轻量写“帝国历冬末”“册封文书第七火钟盖印”等低承诺表达；若要确定正式历法名，需要 Bible/Patch 后续处理。

## v12 重写硬规则

### 1. 主角每章必须输一小截

- `ch01`：冬厅不能写成莱恩用议事录全胜。家族至少反切一刀，例如缩短赴任期限、扣掉一半正经补给、让他签下放弃主城求援的文书，或把加雷斯调给他变成“旧兵清废”而非正式护卫。
- `ch02`：莱恩至少误判一次现场风险，例如把尸铃当外部警戒，结果它其实已经点名墙内人；或他选择保马车导致断腿马拖慢队伍，反而失去一桶火油/一名残兵冻伤。
- `ch03`：莱恩立规不应立刻服众。至少一条规矩被当场踩线，造成水、盐、火油、劳力、伤员、信任中的一项损失。

验收标准：三章读完，读者应觉得莱恩能撑事，但不是天降完美领主。

### 2. 胜利必须是局部且带余账

- 禁止“44/44 完美无损”式零损闭环成为爽点核心。
- 允许小胜，但必须留下余账：有人受伤、盐少一袋、火油少半罐、井封死、孩子还烧、老兵不满、奥莎暂时合作但不信任。
- 每次胜利后都要问一句：这次活下来，换掉了什么？

验收标准：章末钩子来自后果，而不是系统承诺。

### 3. 星火疆图只显示局部事实

允许显示：

- 已触碰范围内的污染浓度、残缺边界、火种状态、人口粗数、可见物资、风险趋势。
- 物件状态：旧界碑登记缺页、火种塔残基失联、西井污染上升、尸铃骨铃异常。
- 资源事实：粗盐、石灰、火油、旧界碑石、黑土、废铁、木料、伤员数量。

禁止显示：

- “任务：完成立火立规立界。”
- “奖励：火种塔残材 1/7。”
- “最佳路线：先封井再点火再修墙。”
- “收益预测：修好北墙可提升治安 20%。”
- “怪物弱点：用某物即可击杀。”

推荐写法：

- 不写攻略句：`完成立火、立规、立界，可解锁临时火界。`
- 改写为事实句：`火种塔：熄灭。界碑边界：断裂。西井污染：上升。墙内秩序锚点：不稳定。`
- 让莱恩自己推理：火没有，界断了，人乱了，所以他必须先处理火、人、边界。

### 4. UI 展示要短、脏、不完整

- 每次星火疆图展示不超过 3 到 5 行。
- 每行只给名词和状态，不给解释段。
- 第一次出现可以破碎、闪烁、缺字，体现它还没真正归位。
- UI 后必须接现实动作，不能接长篇心理分析。

示例方向：

```text
【碎星领外缘】
火种：熄灭
界碑：缺页
污染：西井上升
人口锚：混乱
```

这类显示只告诉读者“哪里坏了”，不告诉读者“怎么赢”。

### 5. 内心 OS 降频且去公式化

- 每章 OS 总量建议：`ch01` 2 到 3 处，`ch02` 1 到 2 处，`ch03` 1 到 2 处。
- 尸铃袭击、梦行、井边争水、处罚违规时，不写俏皮 OS。
- OS 只承担三类功能：压力反应、自我校正、代价感。
- 每句 OS 后必须落动作、问话、命令或身体反应。

禁止反复使用的公式：

- 看见异常 -> 心里吐槽 -> 立刻总结。
- “这不是 X，这是 Y。”
- “他终于明白……”
- “答案已经很清楚。”
- 用 OS 替配角说服读者。

推荐替代：

- 身体先暴露硬撑：指节发白、喉咙发干、耳鸣、膝盖旧伤、冻僵的手没握稳杯沿。
- 内心只留半句：`别抖。先数人。`
- 然后立刻动作：他点名、封井、让加雷斯压人、让奥莎带孩子退开。

### 6. ch02 尸铃袭击提前爆，但不能升级为大型战斗

- 袭击性质：局部、短促、贴脸、规则感强。
- 触发方式：尸铃点名、梦行、井绳自响、墙内有人听见死者喊名、骨铃从门洞内侧响。
- 直接代价：一人受伤或被污染、井被迫封死、火油/粗盐提前消耗、布兰恩修门材料被打断、奥莎对莱恩更不信任。
- 结尾状态：袭击被压下或暂时阻断，但不是彻底解决；第三章承接其余波立规。

### 7. ch03 立规必须有真实违规

至少写一个“明知规矩仍踩线”的人：

- 偷水：有人趁封井混乱从污染井取水给孩子。
- 抢粮：有人撬粮车，理由是新领主明天可能先跑。
- 私放：旧兵想放自己亲属进内棚，破坏隔离线。
- 抗命：布兰恩拒绝修没有材料的门，要求先给工具和铁钉。
- 护短：奥莎藏下发热孩子，不肯交给玛伦或临时伤棚。

裁决要求：

- 不能只靠莱恩一句狠话。
- 必须有人执行，有人反弹，有人付代价。
- 处罚要体现“罚也给路”：罚役、扣私藏、公开补偿、优先救急、让违规者承担危险岗位。
- 莱恩自己也要付成本，例如少一袋盐、少一罐火油、少一个能干活的人，或失去一部分民心。

### 8. 配角每人带一个私欲或恐惧入场

`v12` 不要求所有配角都戏多，但每个出场配角都必须带行动目标。

- 加雷斯：怕莱恩年轻逞强害死残兵；行动上会顶命令、改防线、优先保兵。
- 奥莎：怕贵族又拿孩子和病人做牺牲；行动上藏水、护人、公开质问。
- 布兰恩：怕被迫做无用工、背修不好门的锅；行动上索要工具、拒绝空话、擅自拆旧铁。
- 罗维：怕妻儿死，可能偷水或被尸铃点名；行动上踩线，成为第一条规则的试金石。
- 账务官/法务官：怕手续担责；行动上扣物资、改措辞、逼莱恩签字。
- 艾德里克：不急着杀弟，想让莱恩盘活烂地后再收割；行动上给体面话术和隐形限制。

验收标准：每场至少有两个配角不是“看莱恩反应”，而是在推动自己的利益。

### 9. 奇幻世界契约用物件嵌入

不要用大段世界观说明。每个场景选择 1 到 2 个世界物件，让它承担动作功能。

可用物件：

- 历法：文书角落的帝国历冬末日期、火钟计时、霜月口语称呼。注意：具体历法名未正式批准，暂不固定专名。
- 帝国：册封令、灰蜡盒、边军撤防章、法务官记录、旧界碑登记册。
- 教会：圣火教会净化印、缺席的巡查签、玛伦或教会药瓶的圣火漆封。
- 火种塔：失联回执、熄灭塔芯、火种灰、塔基冷光。
- 界碑：缺页登记册、裂开的界石、母亲遗物黑银指核与旧界碑主核的反应。

写法要求：

- 物件必须改变人物行动。比如“教会净化印缺席”导致无法合法开井；“界碑登记缺页”导致莱恩不能确认边界；“火种塔熄灭”导致夜里没有安全线。
- 不解释全体系，只让读者先记住物件和后果。

### 10. 章末钩子必须从代价里长出来

- `ch01` 钩子：不是“他拿到了金手指”，而是“他带着不足的东西出城，星火疆图只显示碎星领关键状态缺失。”
- `ch02` 钩子：不是“尸铃很恐怖”，而是“尸铃已经伤到墙内人，井被封，水危机在明早前会爆。”
- `ch03` 钩子：不是“临时秩序成功”，而是“秩序刚立住十二时辰，代价已经耗掉一半救命物资，火种塔残基亮起一息，引来更深处回应。”

## 逐章改法

### ch01：从“冬厅反压”改成“抢到废料但输掉退路”

保留：

- 西塔旧库核账 -> 冬厅传召 -> 灰蜡盒 -> 正式册封的逻辑链。
- 莱恩通过旧库经验问活人、火种塔、边军、物资。
- 艾德里克软刀、公爵裁决、账务官担责恐惧、加雷斯老兵口令的声音分叉。

必须新增或改写：

1. 莱恩误判家族底线。
   - 他以为议事录能逼家族多给正经补给。
   - 艾德里克反切：可以给旧库清废物，但正式补给一律按“试炼低配”走。
   - 结果：莱恩拿到的是废料、粗盐、石灰、旧测绘匣，而不是足够粮车和正规护卫。

2. 让放逐有明确代价。
   - 他被要求在极短期限内离城。
   - 他签下“到任后自行承担边地守备”的文书。
   - 他失去主城账务权限或旧库身份，从此不能再用家族名义调资源。

3. 星火疆图不发任务。
   - 不写“立火、立规、立界”的任务式提示。
   - 只显示：权限待归位、火种塔状态未知、界碑登记缺页、册封名义成立但实际掌控为零。
   - 莱恩自己从这些状态推断：没有火、没有界、没有人服，他过去就是接一块会吃人的地。

4. 降低 OS 密度。
   - 开头可保留一处身份落差 OS。
   - 冬厅交锋中只保留一处代价 OS。
   - 接令时用身体硬撑代替长 OS：手指被黑银指核烫出血、膝盖在石地上麻掉，但他不能抬头。

5. 轻量嵌入世界契约。
   - 册封令角落出现帝国历日期，但不固定新历法专名。
   - 灰蜡盒、边军撤防章、缺页界碑登记册、缺席的圣火教会巡查签，分别说明合法性、军事放弃、边界不明、净化缺口。

章末目标：

- 莱恩没有赢冬厅。他只是从处决仪式里撬出一批别人不要的活命废料。
- 读者情绪应是：憋屈、冷怒、替他急，但愿意看他怎么把废料变成活路。

### ch02：从“抵达后预备危机”改成“尸铃已经咬进墙内”

保留：

- 路途冷、荒、破和补给窘境。
- 墙、柴、门、井的检查顺序。
- 布兰恩和奥莎的质疑。
- 碎星领既烂又有价值：黑土、旧矿、废塔、旧界碑石基等。

必须新增或改写：

1. 路途给一次误判和损耗。
   - 莱恩根据星火疆图的污染边缘提示绕开冻死林，但它不告诉安全路线。
   - 他选了一条“看起来能保车”的路，结果断腿马拖慢队伍，冻伤一名残兵或损失一桶火油。
   - 这样金手指显示局部事实，选择和代价仍由莱恩承担。

2. 星火疆图只做局部仪表。
   - 显示“污染残留”“边界不稳”“西井异常”“火种塔熄灭”。
   - 不给“绕行路径”“尸铃用途”“净化方案”。
   - 如果出现资源提示，只显示被莱恩亲眼看到或触碰过的东西。

3. 提前引爆尸铃袭击。
   - 到达后尸铃不是静态钩子，而是主动点名。
   - 可执行事件链：
     - 门洞内侧骨铃响，不是风吹。
     - 一个墙内人听见死者喊名，梦行向西井走。
     - 奥莎冲上去拉人，因为那人关系到她的孩子/病棚/本地人。
     - 莱恩误以为先控人群即可，结果井绳自己绷直，污染水溅出，伤到一名残兵或孩子。
     - 加雷斯擅自下重手压人，导致人群更怕残兵。
     - 莱恩不得不提前消耗粗盐或火油压住污染。

4. 袭击必须短，不写成大型战斗。
   - 不出现成群夜喉围攻。
   - 不让莱恩用系统秒解。
   - 袭击结束后，尸铃仍未彻底处理，井也不能立刻恢复。

5. 配角主动行动。
   - 奥莎不是单纯质疑，她要抢回被点名的人或护住孩子。
   - 布兰恩不是单纯顶嘴，他发现门闩根本受不住，要求先拆废铁。
   - 加雷斯不是单纯听命，他为了保兵可能提前动手，制造民众恐惧。

章末目标：

- 尸铃袭击被临时压住，但水源危机扩大。
- 莱恩失去一部分物资和信任，明白自己不是来接领地，是来接一口已经裂开的锅。
- 第三章必须承接：封井、分水、处罚违规、修门、立火界。

### ch03：从“顺序立火规界”改成“踩线后才有规矩”

保留：

- 资源清点要和谁先死、谁先抢绑定。
- 奥莎公开质疑主角。
- 布兰恩、加雷斯、奥莎各自用自己的能力解决问题。
- 章末形成秩序雏形，但领地仍危险。

必须新增或改写：

1. 立规之前先失控。
   - ch02 尸铃余波导致井被封、水不够、伤员发热。
   - 莱恩想先清点再分配，但人群等不了。
   - 有人偷水或撬粮车，理由要成立：孩子烧、老人渴、怕新领主明天跑。

2. 违规者不能是纸片坏人。
   - 推荐用罗维或本地人：他不是恶，而是被恐惧逼到踩线。
   - 奥莎护短，不是反派；她知道违规不对，但她更怕孩子死在贵族规矩里。
   - 这样“立规”变成真实民生冲突，而不是主角展示权威。

3. 裁决必须有双重代价。
   - 对违规者：罚役、守墙、交出私藏、公开认错或承担危险岗位。
   - 对莱恩：拿出一部分本就不足的粗盐/热水救孩子，导致后续防污染资源减少。
   - 对人群：知道规矩不是空话，也知道规矩会疼。

4. 莱恩必须被纠正一次。
   - 奥莎指出他按人数分水会害死病人。
   - 布兰恩指出他想修门但没有合格门轴。
   - 加雷斯指出他把残兵放错位置会让西墙空出来。
   - 莱恩接受纠正，但把纠正纳入规则，不让配角轻易夺走控制权。

5. 星火疆图初启只确认状态，不发奖。
   - 当火盆、门闩、封井、分水规则暂时成立后，星火疆图可以显示：
     - 人口锚：暂稳
     - 西井污染：封闭中
     - 临时火线：十二时辰
     - 火种塔残基：低反应
   - 不写“奖励火种塔残材 1/7”。可以写莱恩在现实里捡到一枚被烧裂的骨铃/塔灰/界石碎片，星火疆图只标记它有反应。

6. 章末秩序必须带裂缝。
   - 奥莎接下清井或病棚，不代表信服，只代表她看见莱恩愿意为病人付盐。
   - 布兰恩修门，不代表投靠，只代表他拿到了废铁和工具。
   - 加雷斯执行轮防，但仍警告莱恩别把临时火界当城墙。

章末目标：

- 第一条规矩真正落地，因为有人违规并付了代价。
- 莱恩得到一小块掌控感，但读者能看到掌控感是用物资、人情和伤口换来的。
- 下一章钩子应指向：临时火线只有十二时辰，火种塔残基亮起一息，墙外更深处有回应。
