- 书名：放逐边地开拓录
- 范围：ch01-ch03 v12 -> v13
- 审阅对象：
  - `books/exiled-frontier-lord/candidate/drafts/ch01_draft_v12.md`
  - `books/exiled-frontier-lord/candidate/drafts/ch02_draft_v12.md`
  - `books/exiled-frontier-lord/candidate/drafts/ch03_draft_v12.md`
- 审阅目标：根据作者最新批评，输出 v13 语言、逻辑、共情返修验收清单

## 结论

v12 的大结构可以保留：旧库到冬厅、赢一半输一半、杉骨林死人、带尸入领、抢水立规、临时火界，这些方向符合正式合同和开篇方法包。

但 v12 仍不能直接进入下一轮审批。最高风险不是剧情骨架，而是读者近距离阅读时的三类断裂：莱恩的 OS 像冷硬总结器，第二章预警后行动反应不足，乔里死亡前的人味不够。读者会理解“这里死人了”，但未必会心里疼；会理解“莱恩犯错了”，但会怀疑这错是作者硬让他犯；会理解“艾德里克在使坏”，但记不住他作为长兄压迫者的独特锋刃。

v13 应定位为“语言逻辑共情返修”，不是重搭三章剧情。

## 最高风险问题

### 1. 必须改：ch02 预警后莱恩无有效反应，乔里死亡会被读者判为硬编

- 出戏位置：`ch02` 第 114-119 行，星火疆图已经显示“异常源：尸铃回响”“西侧河沟：冻土松动”；第 121-125 行莱恩只评价“没有推荐、没有答案”；第 187-195 行才开始考虑是否烧火油；第 199 行尸铃直接点名乔里。
- 读者这一拍会想：既然主角和金手指都知道“尸铃回响”，为什么没有提前问加雷斯尸铃规则、让人远离林线、打开火油封泥、给乔里换岗或让残兵双人看车？
- 情绪损失：乔里之死本该让读者替莱恩痛，但现在容易变成“作者让他慢一拍”。这会削弱莱恩失手的可信度，也削弱商业连载最重要的“主角强但会被现实打断”的快感。
- v13 验收：
  - UI 或现场第一次提示“尸铃/铃声/点名风险”后，500 字内必须出现莱恩的具体反应：询问、布防、开封火油、撒盐、换人、禁单独行动，至少一种。
  - 莱恩可以判断错，但必须错在信息缺口，不是错在看见警讯却不处理。
  - 乔里死亡的直接因果应改为：莱恩做了预防，但把尸铃理解成“林内外袭”，没想到它已经通过车辕、名牌或伤口点名乔里。
  - 加雷斯的纠错要更精准，不只骂“舍不得油”，还要指出莱恩错在哪一层规则上。

### 2. 必须改：乔里死亡缺少死前血肉，读者共情不够

- 出戏位置：`ch02` 第 92-100 行乔里第一次出现，有红发、木名牌和“马也记损耗吗”；第 155-177 行受伤；第 199-239 行被点名死亡。信息够用，但人味还没扎进读者心里。
- 读者这一拍会想：乔里是“被安排来死的车手”，不是“我刚认识的倒霉人”。
- 情绪损失：死亡变成剧情代价，不是情绪代价。商业连载里，早期牺牲角色不需要长篇身世，但必须有一个让读者记得住的生活钩子。
- v13 验收：
  - 乔里死前至少增加两个轻量人味节拍：一个动作能力节拍，一个私心/牵挂/习惯节拍。
  - 人味必须发生在死亡前，不能死后才用“红桥坊、车手、木名牌”补。
  - 乔里至少主动帮队伍解决一次小问题，例如认出哪罐火油漏、护住马、提醒车轴、替残兵拉住粮袋。
  - 乔里的恐惧要具体，不是泛泛怕死；可以怕名字被漏记、怕马被白杀、怕回执写错连累家人、怕自己这种临时车手死了无人认。
  - 死后余波至少有一个他人反应，不只莱恩记账。残兵、加雷斯或另一个车夫要用一句话或一个动作证明“这个人刚才还在队伍里”。

### 3. 必须改：莱恩 OS 冷、硬、同构，缺少腹黑和精明趣味

- 出戏位置：三章高频出现同一类判断句。典型包括 `ch01` 第 56、66、90、108、114、168、228、262-264 行；`ch02` 第 121-125、249-265、325-329、345-347 行；`ch03` 第 57-61、115-117、127、165-167、195-199、339-345 行。
- 读者这一拍会感到：莱恩一直在“冷静总结”，像审稿人替剧情盖章；但他作为会算账、会记仇、会借制度阴人的年轻领主，少了“聪明得有趣”的味道。
- 情绪损失：主角魅力会被压成冷面机器。开篇可以冷硬，但不能全靠“不是 X 是 Y”“没有答案”“至少”“很好”这类句式维持近感。
- v13 验收：
  - 每章保留少量 OS，但要区分功能：有的用于压力反应，有的用于小算计，有的用于自嘲式精明，不能都做总结。
  - 删除或改写重复链条：`没有推荐 / 没有答案 / 很好`、`不是 X，是 Y`、`至少`、`好消息 / 坏消息` 不得连续成为三章主语感。
  - 莱恩的腹黑趣味要落在动作上：他如何让书记员不得不记、如何让账务官自己承认破损、如何把艾德里克的体面话反扣成记录风险。
  - OS 后必须接动作或选择，不要接一段解释。读者应通过“他做了什么小坏招”觉得他精明，而不是通过作者告诉读者他会算。
  - 尸铃袭击、乔里濒死、孩子发烧、井边抢水时不得插轻佻 OS；轻俏只放在压力缝隙。

### 4. 必须改：艾德里克性格有方向，但不够鲜明

- 出戏位置：`ch01` 第 118、128、148、192、216、290 行。艾德里克已有“温和、弟弟、恩典、试炼、损耗自负”的软刀方向，但主要靠通用贵族话术，个人策略不够咬人。
- 读者这一拍会想：这是一个会阴人的贵族长兄，但还不是“艾德里克这个人”。他不像地痞，但也暂时不像能长期压迫主角的强敌。
- 情绪损失：家族线的压迫感会变浅。长兄如果只是优雅嘲讽，后续反压爽点就不够高。
- v13 验收：
  - 艾德里克至少有一个“把恶意包装成替莱恩好”的标志性动作，而不只是一句台词。
  - 他的刀要落在制度上：提前准备空白附款、诱导莱恩主动提出立刻赴任、让“损耗自负”看起来是替旧库免责，实际是把死人账扣给莱恩。
  - 他的台词要更像贵族软刀：表层祝福、内层锁链、尾部留证据。避免只说“别死得太难看”这类泛反派句。
  - 不能让他长篇解释阴谋，也不能让他情绪破防。他越体面，读者越应觉得他危险。

### 5. 必须改：ch01 开头“怎么又是你？”拟人化突兀

- 出戏位置：`ch01` 第 22-25 行，莱恩在碎星领三个字下画线，随即出现“怎么又是你？”
- 读者这一拍会疑惑：这是莱恩在对地名说话，还是作者对读者眨眼？开篇尚未建立莱恩与“碎星领”反复纠缠的关系，第二人称拟人化来得太早，偏现代吐槽，削弱冷硬贵族旧库的质感。
- 情绪损失：第一屏本应建立旧库、烂账、体面处决的压迫，却先让读者听到一句轻飘的拟人 OS。
- v13 验收：
  - 第一句 OS 应改成更贴莱恩性格的账册式或记仇式反应，例如“碎星领又冒出来了”这一类低拟人、低跳脱表达。
  - 如果保留第二人称，必须先用一两句建立“他已经在多份旧账里反复见过这个名字”，让“你”有对象、有情绪积累。
  - 开篇前三百字内不使用过于网感的俏皮句。轻松感可以有，但要从旧库破烂、账务荒谬和莱恩的小算计里长出来。

## 次级问题

### 建议改：星火疆图的“无攻略感”表达有点自我说明

- 出戏位置：`ch02` 第 121-125 行、`ch03` 第 57-61 行、`ch03` 第 339-341 行。
- 问题：文本反复强调“没有推荐、没有答案、没有成功、没有结算词”，读者会感觉作者在解释自己没有写系统文。
- v13 验收：让 UI 自然短、脏、不完整即可，不要反复由莱恩或旁白声明“它没有给答案”。读者能从界面内容看出来就够。

### 建议改：ch03 的“未减员”容易冲淡乔里死亡

- 出戏位置：`ch03` 第 329-337 行，星火疆图显示“领民锚点：44，未减员”，紧接“随行损耗：乔里死亡”。
- 问题：从系统层面看没有错，乔里不是领民；从读者情绪看，这一行会把刚建立的死亡代价洗成统计胜利。
- v13 验收：可以保留“44 未减员”的经营信息，但不要让它成为章末爽点主句。章末应先承认乔里死亡和火油消耗，再说领地暂时没再死人。

### 建议改：危机类型在 ch02/ch03 之间略重复

- 问题：两章都出现剥皮狗状夜喉、骨铃、点名、盐火。结构上成立，但阅读体感可能像同一种怪连打两次。
- v13 验收：ch02 重点是“路上点名导致乔里死亡”，ch03 重点是“井、水、人群和规矩被尸铃利用”。怪物外形可弱化重复，把恐怖重心转到人群失控和井声诱导。

## 逐章 v13 验收标准

### ch01 验收标准

- 开篇第一屏稳住旧库冷硬质感，不再用无铺垫的“怎么又是你？”。
- 莱恩 OS 有精明趣味：至少一处小算计让读者感到他会借文书和体面反杀，而不是只会冷静总结。
- 艾德里克完成一次清晰软刀动作：他让莱恩看似拿到资源，实际签下更重责任。
- “赢一半，输一半”的结构保留，但输的部分要更具体地压到莱恩身上：退路、责任、人手、补给或名声至少一项被锁死。
- 星火疆图只显示名义、疆界、锚点、火种塔等状态，不给任务、路线、收益。

### ch02 验收标准

- 乔里在死亡前被建立成一个有用、有怕处、有小动作的人。
- 星火疆图或现场提示尸铃后，莱恩必须立刻采取预防动作。
- 莱恩的失误来自错误判断尸铃机制或低估附着范围，不是无视警报。
- 火油迟疑仍可保留，但要建立“为什么迟疑合理、为什么仍然错、错在哪里”。
- 加雷斯纠错必须保留，并更具体地指出边境经验差距。
- 章末仍以“带尸入领、名字被带进碎星领”为钩子。

### ch03 验收标准

- 乔里死亡继续产生人心后果：残兵、领民或莱恩本人至少一处反应要让读者记得这是刚死的人。
- 霍伯抢水、奥莎质疑、罗维跨线、布兰恩要工具、加雷斯压兵这些有效冲突保留。
- 第一条规矩仍是“罚 + 活路”：惩罚违规者，同时给病人和弱者明确活路。
- 星火疆图展示状态即可，少用“未减员”“没有成功”等自我说明式句子压过情绪。
- 章末小爽点保留为带伤小胜：水只稳十二时辰、火油少两罐、乔里已死、火种塔只亮一息。

## 严禁项

- 严禁保留无铺垫的“怎么又是你？”作为开篇 OS。
- 严禁让星火疆图提示尸铃后，莱恩没有任何对应行动。
- 严禁把乔里写成只为死亡服务的临时工具人；死后补籍贯不算建立血肉。
- 严禁继续堆叠“没有答案 / 没有推荐 / 没有成功 / 不是 X 是 Y / 至少”作为主角近感。
- 严禁把艾德里克写成粗暴反派、嘴炮反派或会当场破防的普通恶兄。
- 严禁为了补人物而写长篇身世说明，新增血肉必须通过动作、对话和选择完成。
- 严禁让 ch03 的经营统计抹平乔里死亡的情绪账。

## 保留项

- 保留 ch01 旧库核账 -> 冬厅册封 -> 旧库清废 -> 损耗自负 -> 星火疆图初显的主链条。
- 保留莱恩争到废料但失去向导、净祷士和退路的“半胜半败”。
- 保留 ch02 杉骨林局部尸铃危机、河沟误判、火油迟疑、乔里死亡、加雷斯纠错。
- 保留星火疆图降噪原则：只给状态，不给推荐路线、任务、奖励和结算爽词。
- 保留 ch03 带尸入领、封井反弹、霍伯抢水、奥莎接管点名、布兰恩按工匠逻辑行动、罗维因妻子被诱导后守火。
- 保留章末带伤小胜：临时领主锚定、水只稳十二时辰、火油消耗、火种塔只亮一息。

## 返修优先级

1. 先修 ch02 因果链：尸铃提示后的反应、乔里死因、加雷斯纠错。
2. 再修乔里血肉：死前两处人味，死后一处余波。
3. 再修三章 OS：删重复句式，补莱恩小算计和腹黑趣味。
4. 再修 ch01 艾德里克：给他一个制度软刀动作和更有记忆点的台词。
5. 最后统一清理 UI 自我说明句，保留短状态，不解释“不像系统”。

## 快速评分

- 情绪拉力：7/10。骨架有效，但乔里共情不足拉低死亡重量。
- 节奏推进：8/10。三章推进顺，v13 不需要大改结构。
- 人物声音：6/10。奥莎、布兰恩、加雷斯较稳；莱恩 OS 和艾德里克仍需辨识度。
- 逻辑一致：6/10。最大短板是 ch02 预警后行动不足。
- 信息清晰：8/10。读者能看懂发生了什么，但部分 UI 说明太显作者意图。
- 钩子力度：8/10。带尸入领和火种塔一息都能拉下一章。
- 商业可读性：7/10。返修后有机会到 8+；当前会被“硬死一个人”和“主角太冷”拖留存。
