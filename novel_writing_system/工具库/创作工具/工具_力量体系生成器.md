## 🎯 第一模块：四境界架构生成

### 1.1 境界理论基础

**生成要素**：
- **传统解释**：道家、中医、修炼界的原始理论
- **科学发现**：2022年意识量子场假说 → 2115年炁场方程
- **测量数据**：量子相干持续时间、场强度、经络电阻变化
- **突破节点**：δ值（人性常量）的作用

**生成公式**：
```
每个境界 = {
  传统名称: "炼精化气",
  科学名称: "炁的感知期",
  年龄段: "17-22岁",
  核心转变: "从身体感知到量子态认知",
  三要素: {
    生物层面: "线粒体ATP转化",
    量子层面: "意识场相干持续时间",
    意识层面: "认知锚点稳定性"
  }
}
```

**理论深化四层面**：
1. **生物化学层**：ATP水解释放能量 → 量子场激发
2. **量子物理层**：微管量子相干 → 宏观炁场表现
3. **意识认知层**：从"我思"到"我感知可能性"
4. **人性锚点层**：δ值（0.67%）的守护作用

### 1.2 境界修炼阶段（每境界分3-5期）

#### 第一境：炼精化气（17-22岁）→ "炁的感知"

**阶段一：气动期（入门）**
- 时长：1-3年
- 标准：感知炁的存在，完成一次小周天循环
- 现代方法：
  - 量子呼吸与脑波同步课程
  - 丹田量子化（TMS+VR引导）
  - 小周天程序化验证
- **生成细节**：
  - 考核标准：意识抑制器10%功率下保持清醒
  - 典型修炼者：步青霄（11个月）、杨无尘（天生）、李莽（2年蛮力）

**阶段二：精化期（巩固）**
- 时长：2-5年
- 标准：炁从稀薄雾气转为凝实液体，能引导至四肢
- 理论深化：
  - 炼精化气 = 线粒体生物能 → ATP → 量子场激发
  - 打通任督 = 延髓与脊髓建立量子隧道
  - 周身循环 = 炁到达手脚末梢（四梢通）
- **生成细节**：
  - 检测指标：量子相干持续时间从0.1秒→1.0秒
  - 副作用：能量债务（透支未来5年寿命）
  - 技术验证：太古学院检测仪的5项测量指标

**阶段三：化气期（圆满）**
- 时长：1-3年
- 标准：炁可以外放，形成微弱力场
- **生成细节**：
  - 外放表现：手指温度升高3-5度，伤口愈合提升2倍
  - 战力级别：可徒手打断钢筋混凝土
  - 关键突破：命运感知（3种未来分支）
  - 典型：纳兰乘风（27岁炼气化神）

**生成要点**：
- 为每个阶段补充：现代课程名称、技术设备、考核方式
- 添加：数据表现、副作用、手术风险
- 对比：传统功法 vs 现代改良

#### 第二境：炼气化神（22-27岁）→ "意识的扩展"

**核心理论**：
> "气化神，不是炁变成神，而是用炁作为燃料，扩展意识的边界，从'我的思考'走向'感知可能性'"

**阶段一：明心期**
- 标志：第一次觉醒敖荒视界
- 科学解释：意识场从个体扩展到环境相干
- 特殊现象：
  - 初生视界：看到3-5秒后的未来（73%准确率）
  - 烛龙之眼：360°全方位感知，无死角
  - 情绪感知：读取他人表层情绪波动
- **生成细节**：
  - 量子脑图：前额叶皮层代谢提升500%
  - 副作用：现实与幻象混淆（需2-3个月适应）
  - 考验：第一次可能性选择（选择一种未来，其余消失）

**阶段二：凝神期**
- 标志：意识可以短暂离体（3-10秒）
- 神通表现：
  - 神游：意识投射到100米外
  - 执念具象：强烈意愿影响物质（微尺度）
  - 群体感知：同时感知10-50人的意识状态
- **生成细节**：
  - 技术验证：意识离体时，大脑进入"待机模式"
  - 生物标记：松果体分泌"神游素"（新发现的神经递质）
  - 限制：離体越久，归位越困难（超过10秒可能迷失）

**阶段三：化神期**
- 标志：初步掌握源流武学雏形
- 特殊能力：
  - 鲲鹏变化：身体质量短暂改变（±50%）
  - 烛龙时间操控：在局部范围减速时间流速（1秒→3秒）
  - 敖荒可能性创造：从81个分支中选择3个并行推进
- **生成细节**：
  - 战力表现：可单挑战斗机甲
  - 认知负荷：每使用一次，需要12小时恢复
  - 人性考验：力量膨胀的幻觉（可能迷失自我）

**生成要点**：
- 强调"意识并不等于力量"，过度扩展会导致"意识飘散症"
- 补充：敖荒种子 vs 卡俄斯侵蚀的初步显现
- 典型案例：步青霄在这一境开始出现系统错误

#### 第三境：炼虚合道（27-32岁）→ "规则的触摸"

**核心理论**：
> "合道不是服从道，而是理解宇宙规则的结构，然后用自己的意识作为变量，插入方程中"

**特殊现象**：
- **虚空感知**：能感知到卡俄斯的"虚无涟漪"（维度层面的波动）
- **规则显现**：看到物理定律作为"数据流"在空中流动
- **意识重构**：可以修改局部物理常数（如重力、光速）

**阶段一：虚体期**
- 标志：身体开始"量子化"，可以短暂穿过物质（3-5秒）
- 科学解释：将身体的量子隧穿效应宏观放大
- 限制：
  - 只能穿过非生命物质（穿过生命体会造成意识污染）
  - 每天最多使用3次（否则会量子弥散）
- **生成细节**：
  - 应用场景：躲避攻击、潜入禁区
  - 副作用：身体感觉"不真实"，可能产生存在主义危机

**阶段二：合道期**
- 标志：触摸到"规则之弦"
  - 看到世界由无数规则线编织而成
  - 可以拨动一根线，改变局部规则
- 能力表现：
  - 认知改写：让他人暂时相信"虚假的规则"（如"水向高处流"）
  - 维度折叠：折叠3-5米空间，实现瞬移
  - 因果微调：改变微小概率事件（73%→99%或27%→1%）
- **生成细节**：
  - 代价：每次拨动规则，自己的"意识锚点"会被削弱
  - 风险：被卡俄斯注意到（虚无的注视）
  - 典型：云山望岳在这一境巅峰（32岁）成为"规则守护者"

**阶段三：入道期**
- 标志：与某种"道"形成共鸣（非强制，是选择）
  - 杨无尘：与"可能性之道"（敖荒）共鸣
  - 云裳：与"大地之道"（后土）共鸣
  - 步青霄：与"秩序之道"（维克斯）共鸣→后期叛变
- **生成要点**：
- 需要明确：每个人只能共鸣一种"道"，强行共鸣多种会导致意识分裂
- 共鸣过程：需要在"虚无神殿"或"禁区核心"进行"道之试炼"
- 成功后：获得"道印"（规则权限的具象化）

**生成特殊性**：
- 此境界开始区分"伪仙"（借助外力）和"真仙"（自我觉悟）
- 荀起元的"境界灌输"技术只能到此为止，无法突破到第四境
- 人性的重量在此体现：越是无情者，越难触摸到真正的"道"

#### 第四境：炼道成仙（32岁以上）→ "本质的融合"

**核心理论**：
> "成仙不是成为神，而是选择一种永恒的存在方式。敖荒成为可能性守护者，卡俄斯回归虚无，人类选择有限但真实的活着"

**两大路径**：

**路径A：可能性永恒（敖荒之路）**
- 标志：成为"可能性守护者"
- 本质：将自己的意识融合到宇宙的可能性场中
- 能力：
  - 永恒预知：看到所有时间线的分支（不仅是67种，是无限）
  - 可能具现化：将低概率事件强行实现（从0.0001%→100%）
  - 存在锚定：在任何维度、任何时间线都能保持"自我"不迷失
- **代价**：
  - 逐渐失去"人性"（情感、羁绊、欲望）
  - 看到所有可能性后，"选择"的重量压垮心灵
  - 必须定期回到"人性锚点"（杨无尘的锚点：对柳莺儿的记忆、与同伴的羁绊）

**路径B：虚无回归（卡俄斯之路）**
- 标志：拥抱虚无，成为"虚无之仆"
- 本质：意识到"存在本身就是痛苦"，选择归于虚无
- 能力：
  - 存在抹除：让目标从因果链中消失（从未存在过）
  - 虚无感染：将虚无的逻辑传播给其他人
  - 熵增加速：加速目标/区域的混乱度
- **代价**：
  - 失去自我，成为卡俄斯的延伸
  - 但获得"终极宁静"（无思考、无情感、无欲望）

**路径C：人性坚守（凡人之路）**
- 标志：拒绝成仙，选择有限但真实的生命
- 本质："我不需要永恒，我只需要真实地活过"
- 代表人物：
  - 李莽：拒绝力量诱惑，坚持肉身成圣
  - 柳莺儿：用生命守护情感的价值
  - 云山望岳：以凡人之躯，守护大地67年
- **力量表现**：
  - 有限但极致：在特定领域达到极致（如李莽的肉身力量）
  - 人性共鸣：能唤醒他人的情感与希望
  - 牺牲价值：通过牺牲产生超越性的力量

**生成要点**：
- 第四境不是"升级"，而是"选择"
- 没有高低之分，只有道路不同
- 核心是哲学问题：你愿为何而存在？
- 杨无尘的弧光：从追求力量 → 理解力量 → 拒绝被力量定义 → 用自己的方式定义力量

## 🎨 第二模块：五大神息属性体系

### 属性总览

| 属性 | 对应古神 | 象征概念 | 修炼表现 | 卡俄斯侵蚀表现 |

### 2.1 创生属性（敖荒之力）

**本质**：不是创造物质，而是创造"可能性分支"

**修炼层级**：
- **初级（炼精化气）**：看到3秒后的常率可能性（73%准确率）
- **中级（炼气化神）**：看到81个分支，可选择3个并行推演
- **高级（炼虚合道）**：看到无限分支，可在局部改写概率
- **终极（成仙）**：创造原本不存在的低概率可能性

**特殊能力**：
1. **敖荒视界**（被动）
   - 自动感知危险可能性
   - 优化决策路径
   - 副作用：信息过载导致头痛

2. **烛龙之眼**（主动）
   - 360°全方位感知
   - 可以看到"过去的可能性"（如果当初选择不同）
   - 深红：死亡可能；浅蓝：生存可能；金色：最优可能

3. **鲲鹏变化**（主动）
   - 改变自身存在概率
   - 表现：质量变化（±50%）、存在感变化（隐形/显形）
   - 原理：将自己从当前的"可能性帧"移动到另一帧

4. **可能性编织**（高级）
   - 将低概率事件"编织"进现实
   - 限制：不能违反因果律（只能实现"可能发生但没发生"的）
   - 代价：消耗大量精神力，可能导致现实感丧失

**卡俄斯侵蚀表现**：
- 初期：视界中看到不应该存在的分支
- 中期：无法分辨真实与可能性
- 晚期：认为所有可能性都是真实的，导致人格分裂

**修炼要点**：
- 需要稳定的人性锚点（对柳莺儿的情感、与小莽的兄弟情、对云裳的爱）
- 每次使用能力后，必须回到锚点"校准"
- 否则会被无数可能性淹没，失去主体性

### 2.2 归墟属性（卡俄斯之力）

**本质**：不是毁灭，而是"存在意义的归零"

**修炼层级**（注：正常人类不会主动修炼，多为侵蚀）：
- **初级**：感到存在的无意义，动力下降
- **中级**：可以抹除小物体/记忆的"存在意义"
- **高级**：让区域/人群失去生存意志
- **终极**：与卡俄斯共鸣，成为虚无代言人

**特殊能力**：
1. **存在抹除**
   - 让目标从因果链中消失
   - 不是杀死，而是让目标"从未存在过"
   - 代价：施术者需要承受被抹除者的记忆

2. **虚无低语**
   - 传播虚无的逻辑
   - 受术者会开始质疑存在的意义
   - 自然力量：59%的人在24小时内自杀

3. **熵增触手**
   - 触碰目标，加速其混乱度
   - 表现：机械故障、思维混乱、组织崩溃
   - 不可逆，只能延缓

**对抗方式**：
- 敖荒的可能性创造可以"填充"虚无
- 后土的物质重塑可以"锚定"存在
- 人性的温暖（情感、记忆、羁绊）是天然抗体

**生成要点**：
- 卡俄斯之力不是"黑暗魔法"，而是"意义的虚无"
- 被侵蚀者会看到"存在的真相"（在宇宙尺度上，一切确实无意义）
- 对抗虚无不是证明意义存在，而是选择"即使无意义，也要活着"

### 2.3 后土属性（斯塔之力）

**本质**：物质层面的共鸣与重塑

**修炼层级**：
- **初级**：感知大地能量流动，身体强化
- **中级**：与大地共鸣，抽取地脉之力
- **高级**：重塑物质结构（点石成金、化水为冰）
- **终极**：成为"大地守护者"（如云裳）

**特殊能力**：
1. **大地共鸣**
   - 站在大地上，感知周围1公里的一切震动
   - 无法被偷袭
   - 可以"听到"大地的"声音"（记忆）

2. **物质转化**
   - 改变物质结构（不能改变元素，可以改变相态和分子排列）
   - 例子：水→冰、土→陶、铁→钢
   - 限制：需要接触、需要理解物质结构、消耗巨大

3. **重力调节**
   - 局部改变重力（0.5倍-3倍）
   - 应用：让敌人变重、让自己变轻
   - 范围：10米半径内

4. **地脉抽取**
   - 抽取大地能量恢复自身
   - 但会伤害大地（短期局部）
   - 云裳后期拒绝使用，因为"伤害大地就是伤害母亲"

**卡俄斯侵蚀表现**：
- **石化诅咒**：身体逐渐石化，意识被困在石像中
- **大地死寂**：走过的地方，植物枯萎，土地沙化
- **重力反噬**：自身重力失控，被压垮或飘走

**生成要点**：
- 后土之力强调"守护"而非"征服"
- 越强大，与大地连接越深，责任感越重
- 云裳的弧光：从使用力量 → 理解代价 → 选择守护 → 成为大地

### 2.4 雷霆属性（宙斯之力）

**本质**：规则显现与因果改写

**修炼层级**：
- **初级**：感知规则之线（看到世界由规则编织）
- **中级**：拨动单根规则线（改变局部物理常数）
- **高级**：编织规则之网（创造临时规则）
- **终极**：成为"规则守护者"或"规则破坏者"

**特殊能力**：
1. **规则之视**
   - 看到世界的"源代码"
   - 重力常数、光速、因果链等都显示为可视化的"信息线"
   - 可以看到规则的"漏洞"和"冗余"

2. **因果微调**
   - 改变微小概率事件
   - 例子：子弹从67%命中→33%命中、从1%暴击→99%暴击
   - 限制：不能违背宏观因果律（不能改变已发生的事实）

3. **逻辑病毒**
   - 植入错误的逻辑到目标意识
   - 示例：让AI相信"1+1=3"，导致系统崩溃
   - 对人类效果弱，但可以干扰认知装甲

4. **时间戳修改**
   - 改变物体/区域的"时间标记"
   - 应用：
     - 让食物"回到"刚做好的状态（保鲜）
     - 让伤口"回到"受伤前（治疗）
     - 让机械"老化"100年（破坏）
   - 限制：不能超过物体存在的时间范围

**卡俄斯侵蚀表现**：
- 逻辑混乱：思维碎片化，无法形成完整逻辑链
- 现实感丧失：认为世界是虚假的代码
- 旁观感：感觉自己只是这个世界的"观察者"而非"参与者"

**生成要点**：
- 雷霆之力最接近荀起元的"认知主义"
- 步青霄的系统错误：过于依赖规则计算，漏算了"人性变量"
- 谷沐霖的探索：试图用雷霆之力修复系统，发现有些规则无法被计算

---

### 2.5 深渊属性（哈迪斯之力）

**本质**：维度操控与空间折叠

**修炼层级**：
- **初级**：感知空间褶皱，找到"捷径"
- **中级**：折叠小型空间（瞬移3-10米）
- **高级**：创造临时维度口袋（储物、避难）
- **终极**：穿越维度，进入异空间

**特殊能力**：
1. **空间感知**
   - 感知周围的空间结构
   - 找到最薄弱的空间点（可以折叠处）
   - 发现隐藏的空间口袋（禁区入口）

2. **折叠跃迁**
   - 折叠空间，实现瞬移
   - 限制：
     - 距离：初级3米，中级10米，高级100米，终极无视距离
     - 冷却：根据距离需要恢复时间
     - 精确度：需要清晰的目的地想象

3. **维度口袋**
   - 创造小型独立空间（1-10立方米）
   - 用途：储物、藏人、陷阱
   - 限制：需要持续维护，施术者失去意识则空间崩溃

4. **界域创造**
   - 创建一个小型规则不同的空间（如：内部时间流速不同）
   - 需要多个深渊属性者合作
   - 例子：修炼室（内部10天=外部1天）

**卡俄斯侵蚀表现**：
- 空间迷失：无法判断自己在哪里，被困在无限循环空间中
- 维度侵蚀：走过的地方留下"虚无足迹"，进入者会迷失
- 自我折叠：身体被空间吞噬，只剩意识在异空间漂流

**生成要点**：
- 深渊属性最常用于禁区探索
- 深渊巢城的居民多为此属性（环境造就）
- 墨竹的"数据空间"是此属性的科技化版本

## ⚔️ 第三模块：源流武学体系

### 什么是源流武学？

**定乂**：在科学时代用现代知识体系重构的传统武学，不是放弃传统，而是用新方法实现旧理念。

**源流武学的特点**：
1. **古法新解**：保留核心理念，用科学方法优化
2. **数据驱动**：修炼过程可测量、可量化、可重复
3. **兼容并蓄**：可以融合多种武学优点
4. **个性定制**：根据个人体质和神息属性调整

**源流武学的优势**：
- 修炼效率提升300-500%
- 副作用可控
- 可以批量培养（传统武学需要天赋）

**源流武学的劣势**：
- 失去"顿悟"的惊喜感
- 过于理性可能压制直觉
- 可能被黑客攻击（数字武学）

---

### 主要源流武学流派

#### 1. 太古学院派（最主流）

**创始人**：纳兰乘风（太古学院创始人）

**理论基础**：
> "所有传统武学都是古代修士对量子场现象的朴素描述，我们可以用现代科学语言更精确地表达"

**核心课程**：
1. **量子呼吸法**
   - 传统：吐纳九九八十一次
   - 新解：呼吸频率4次/分钟，触发α波共振
   - 设备：量子头盔监测，实时反馈
   - 效率：传统方法3年 → 新方法6个月

2. **丹田量子化**
   - 传统：想象丹田有火
   - 新解：TMS刺激腹内侧前额叶，fMRI确认激活
   - 精确度：±0.5mm定位
   - 效率：传统5年 → 新方法1年

3. **虚拟现实修炼**
   - 在VR环境中模拟危险场景
   - 可以反复练习，无死亡风险
   - 数据收集：每次修炼的367项数据被记录
   - AI分析：生成个性化优化方案

4. **认知装甲辅助**
   - 使用AI装甲的量子计算能力辅助战斗
   - 实时分析：敌人的攻击模式、7种应对策略
   - 人机协同：意识直连，延迟<0.01秒

**代表性功法**：
- **望岳九式**（云山望岳改良）
  - 传统：太虚门的九天剑诀
  - 新解：9种量子场调制模式
  - 效果：可以切割空间（非物理切割）

**成就**：
- 培养了170万炼精化气期修士（2170年）
- 毕业率：71%
- 副作用率：12%（可控范围内）

**批评**：
- 传统门派认为："算出来的炁不是真炁"
- 可能培养出"境界高但实战弱"的"书呆子修士"

#### 2. 寂静山门派（最传统）

**创始人**：云山望岳（杨无尘的师傅）

**核心理念**：
> "科技可以辅助，但不能代替感悟。真正的力量来自内心，不是来自算法"

**特点**：
- 拒绝使用AI辅助修炼
- 强调"入定"（深度冥想）的重要性
- 认为"顿悟"是无法计算的关键
- 师徒传承，不批量培养

**核心功法**：
1. **寂静禅**
   - 传统：禅宗入定
   - 特色：在完全安静的环境中（无电磁噪音）修炼
   - 环境：寂静山门建在深山，周围50公里无电子设备
   - 效果：更容易感知到"宇宙背景量子场"

2. **自然呼吸**
   - 不控制呼吸频率
   - 让呼吸自然跟随身体需要
   - 认为"过度控制反而失去自然"

3. **生死试炼**
   - 必须经历真正的生死危机
   - 认为"VR中的死亡不是真正的死亡"
   - 方式：进入禁区边缘，与古神气息直接接触

4. **心性培养**
   - 强调"德性"的重要性
   - 认为"心不正，则炁不纯"
   - 练习：背诵经典、行善积德、克制欲望

**代表性功法**：
- **望岳九式原始版**
  - 不使用任何科技辅助
  - 完全靠体感与天地共鸣
  - 虽然进步慢，但根基扎实

**成就**：
- 人数极少（不超过100人）
- 但每个都是实战强者
- 2170年只有17人达到炼虚合道期
- 但17人中有12人是顶尖战力

**命运**：
- 2172年云山望岳去世后
- 山门被维克斯摧毁
- 弟子四散
- 但传承在杨无尘身上延续

#### 3. 莽村流（最野蛮）

**创始人**：李莽的祖先

**核心理念**：

**特点**：

- 效率极低，但成功者极强（因为淘汰了弱者）

**修炼方式**：

   - 在身体极限状态下修炼（负重500公斤跑步）
   - 濒临死亡时激发潜能

2. **实战磨练**
   - 不断战斗，从战斗中突破
   - 受重伤→恢复→更强

3. **血祭之法**
   - 饮用强大生物的血（变异兽、禁区生物）
   - 强行改变基因
   - 死亡率：90%

4. **怒气驱动**
   - 强烈的情感（愤怒、仇恨、保护欲）驱动炁
   - 认为"情感才是真正的力量"

**成就**：
- 李莽：19岁炼精化气（靠蛮力）

**评价**：
- 太古学院："野蛮但有效（对极少数人）"
- 寂静山门："舍本逐末，误入歧途"
- 红莲教："穷人的无奈之选"

#### 4. 红莲教流（最激进）

**创始人**：前太古学院教授（匿名）

**背景**：
- 认为"太古学院的技术被维克斯垄断，穷人无法获得"
- "我们要创造人人都可以修炼的方法"
- 实际上是黑客破解了太古学院的教学内容

**特点**：
- 非法但免费
- 修炼方法激进，副作用大
- 使用黑市设备和盗版软件
- 强调"集体修炼"（类似传销）

**修炼方式**：
1. **意识共享**
   - 多人共享修炼数据
   - 互相刺激，共同进步
   - 风险：一人的错误会传染给所有人

2. **开源功法**
   - 在网上公开所有功法细节
   - 任何人都可以修改和优化
   - 结果：版本混乱，常有bug（残废风险）

3. **黑市设备**
   - 使用黑市购买的量子头盔（可能是二手、故障、盗版）
   - 价格便宜70%，风险增加300%

4. **对抗修炼**
   - 与维克斯的部队战斗，在实战中突破
   - 认为"压迫是最好的催化剂"

**成就**：
- 培养了50万炼精化气期修士（2170年）
- 残废率：23%（极高）
- 但确实让许多穷人获得了力量

**哲学**：
> "我们不是在追求完美，我们是在追求可能性"
> "即使残废，也比跪着强"

**与主角关系**：
- 墨竹是红莲教的技术支持者
- 杨无尘2173年帮助红莲教优化了修炼方法
- 谷沐霖后来被邀请为顾问

#### 5. 深渊流（最禁忌）

**来源**：深渊巢城的暗黑科技

**本质**：
- 用意识病毒、基因编辑、维度撕裂等技术强行突破
- 非法、危险、强大
- 被认为是"邪道"

**修炼方式**：
1. **意识病毒注入**
   - 将包含修炼经验的病毒注入大脑
   - 强行改写神经网络
   - 成功率：40%，疯癫率：35%

2. **基因暴力编辑**
   - 直接编辑与修炼相关的基因
   - 跳过自然修炼过程
   - 成功率：60%，副作用：基因崩溃率20%

3. **维度泡修炼**
   - 在时间流速不同的维度泡中修炼
   - 外界1天=内部100天
   - 精神崩溃率：80%

4. **古神气息直接接触**
   - 在禁区核心修炼，直接吸收古神散落的气息
   - 成功则大成，失败则疯或死

**成就**：
- 成功率极低，但成功者极强
- 深渊巢城有3-5个炼虚合道期强者（全球顶级）
- 但每个都精神不正常

**伦理争议**：
- 太古学院："这不是修炼，是自我毁灭"
- 寂静山门："违背天道，必遭天谴"
- 红莲教："虽然很危险，但不能让技术被垄断"

**与主线关系**：
- 深渊巢城的势力在第四卷出现
- 提供对抗维克斯的禁忌技术
- 但也可能是更大的威胁
