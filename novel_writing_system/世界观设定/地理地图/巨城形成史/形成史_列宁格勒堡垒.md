## 📍 基础信息

**地理位置**：原俄罗斯圣彼得堡地区，纬度59°57′N，经度30°19′E
**城市等级**：二级巨城
**当前人口**：1.5亿
**占地面积**：14,000平方公里（含地下军事设施）
**城市口号**："钢铁永存，意志不朽"
**核心特色**：军工复合体 + 集体主义 + 严寒环境
**别称**："战争机器」、「钢铁堡垒」、「永冻要塞」

## 📜 形成时间线（2080-2170）

### 第一阶段：血与火（2080-2095）「资源战争」

#### 2080年：北极资源战争爆发

```
背景：
  - 全球气候变化，北极冰盖融化约13-15%
  - 露出未开采资源（石油、天然气、稀土）
  - 各国争夺北极控制权

参战方：
  - 俄罗斯：声称拥有北极主权（历史依据）
  - 欧盟：要求国际共享（环保理由）
  - 美利坚残余势力：趁机混入（渔翁得利）

战场：
  - 主要：白令海峡、巴伦支海
  - 次要：圣彼得堡（后勤保障中心）
  - 规模：约23-47万军队投入

战役："列宁格勒保卫战」（2080-2090）
  - 持续时间：10年
  - 伤亡：俄方约23-47万，欧盟约18-23万，美方约12-17万
  - 城市：约40-50%建筑被毁，但工业基础保留

结果：
  - 没有赢家，资源被战争消耗殆尽
  - 三方签署《冰冻协议》（2089年）
  - 列宁格勒获得"英雄城市」称号
  - 但付出惨重代价
```

#### 2085年：钢铁协议签订

```
背景：战争导致经济崩溃，三城无法独立生存
参与方：
  - 圣彼得堡（俄罗斯）
  - 赫尔辛基（芬兰）
  - 塔林（爱沙尼亚）

协议内容：
  - 军事工业一体化
  - 资源共享
  - 人口自由流动
  - 建立"北方工业联合体」

命名争议：
  - 俄：圣彼得堡堡垒
  - 芬兰：波罗的海城
  - 爱沙尼亚：三城联盟
结果：采用"列宁格勒堡垒」，纪念历史

意义：
  - 正式形成巨城雏形
  - 1.2亿人口统一管辖
  - 开始军事化管理
```

#### 2087年：严寒适应基因工程

```
背景：
  - 战争破坏供暖系统
  - 列宁格勒冬季平均-30℃
  - 大量冻伤冻死

荀起元的援助：
  - 提供"极地适应基因」
  - 代价：列宁格勒约35-40%军工订单
遗传改造效果：
  - 体温调节：可在-50℃生存
  - 代谢降低：能量消耗减少30-40%
  - 副作用：情绪淡漠（1-2级）

强制政策：
  - 2088年：所有新生儿强制改造
  - 2090年：拒绝改造者不得进入列宁格勒
  - 2095年：拒绝改造者被驱逐到荒芜地带

文化影响：
  - "钢铁意志」文化形成（情感淡漠被视为美德）
  - 工人平均寿命下降至45-50岁（基因改造代价）
  - 社会效率提升，但人性流失
```

### 第二阶段：钢铁洪流（2096-2125）「集体主义」

#### 2097年：工业熔炉心脏启动

```
建设动机：
  - 需要核心动力源驱动全城军工生产
  - 荀起元提供"永恒熔炉」技术（维度能量转换）
  - 象征："集体意志的具象化」

技术参数：
  - 高度：470米（13城最高工业建筑）
  - 功率：每小时可熔炼47,000吨钢铁
  - 能源：地热能 + 维度裂隙能量（混合供能）
  - 自动化率：87%（仅需13,000人维护）

人文代价：
  - 熔炉需注入"人类意志力」作为催化剂
  - 每天需47名志愿者"献血」（实际为注入精神能量）
  - 志愿者平均寿命缩短15-18年
  - 但获得"钢铁公民」荣誉称号（社会地位提升）
  - 熔炉内部有"47个灵魂祭坛」（纪念牺牲者）
```

#### 2103年：社会信用-军工复合系统建立

```
系统原理：
  - 每个人出生获得"军工信用分」（初始1,000分）
  - 工作、战斗、学习增加分数
  - 消费、犯错、懒惰扣除分数
  - 分数决定社会地位、资源配给、修炼机会

等级划分：
  - S级（10万分以上）：将军、部长、熔炉志愿者
  - A级（1-10万分）：高级军官、工程师、科学家
  - B级（1,000-10万分）：普通工人、士兵
  - C级（100-1,000分）：儿童、老人
  - D级（100分以下）：罪犯、基因改造失败者

结算周期：每30天结算一次
流动率：约13%的人每月跨等级
分配公平性：约35%资源集中在10%人手中
```

#### 2112年：集体意识网络接入

```
技术来源：硅谷城认知技术 + 钟南山意识流理论
系统特点：
  - 全员接入（除D级罪犯）
  - 用途：协调生产、战争指挥、思想统一
  - 效果：生产效率提升45-55%
  - 副作用：个人意识弱化，集体意识强化

杨无尘爷爷事件：
  - 2164年，杨守诚调查时发现网络有"后门」
  - 可强制修改个人记忆（用于"思想净化」）
  - 守诚暗中记录证据（47份文件）
  - 这是导致他失踪的关键原因之一
```

### 第三阶段：扩张与危机（2126-2168）「钢铁极限」

#### 2139年：钢铁产能达到极限

```
产能数据：
  - 钢铁年产量：约4.7亿吨（13城第一）
  - 军工占GDP比重：约45%
  - 工人数量：4,700万人（占总人口31%）

极限问题：
  - 资源枯竭：铁矿石储备仅剩13年开采量
  - 环境污染：空气含氧量降至12-13%
  - 工人健康：工伤率达15-17%（13城最高）
  - 意识分裂：约18-20%工人出现精神症状

政府应对：
  - 启动"钢铁转型」计划（军工转民用）
  - 提高自动化率至87%（减少人力需求）
  - 但遭到军工利益集团抵制
```

### 第四阶段：现代（2170）「钢铁意志」

#### 2170年现状：

```
经济：
  - GDP：约47万亿神息币（军工占35%）
  - 钢铁产量：全球第一（占13城总产量45%）
  - 重工设备：出口到12城（唯一供应商）

军事：
  - 钢铁军团：1,470万人（炼虚合道境界）
  - 装备：符文动力装甲、维度震荡炮
  - 战力：13城最强陆军

社会：
  - 集体意识网络覆盖率达97%
  - 社会流动性低（等级固化）
  - 但居民自豪感强（"我们是钢铁的儿女」）

文化：
  - "钢铁意志」被视为最高美德
  - 每月有"献血日」（47万人参加）
  - 教育：儿童从5岁开始接受"集体主义」训练
```

#### 2170年12月：杨无尘到来

```
到达原因：追查爷爷线索（守诚曾调查过工业熔炉）
调查内容：
  - 熔炉的"人类意志力」来源（发现47,000名"献血者」死亡记录）
  - 集体意识网络后门（能修改记忆的证据）
  - 钢铁军团中13名士兵的"意识异常」（被虚无污染）
关键发现：
  - 在工业熔炉第47层发现爷爷留下的"钢铁意志对抗虚无」笔记
  - 获得"钢铁熔炉47式」（源流武学变种，后融入敖荒之力）
  - 揭露军工利益集团勾结荀起元（提供装备镇压异见）
```

## 📊 城市核心数据（2170年）

### 基础设施
- **工业熔炉**：
  - 高度：470米，47层（含13层精神能量收集区）
  - 日均产量：47,000吨钢铁（可生产47,000套符文装甲）
  - 志愿者：每日47人献血（精神能量），每年约17,155人
  - 副作用：志愿者平均寿命减少15年

- **地下军事设施**：
  - 深度：平均地下47米（防维度打击）
  - 面积：约4,700万平方米（包括13条地下铁路）
  - 容量：可庇护1,470万人在地下生存47天

### 人口与军事
- **总人口**：1.5亿人
  - 工人：4,700万人（钢铁生产）
  - 士兵：1,470万人（钢铁军团）
  - 工程师：470万人（技术研发）
  - 管理层：47万人（政府官僚）

- **钢铁军团**：
  - 编制：1,470万人（13个集团军，每113万人）
  - 装备：符文动力装甲（每套重470公斤，可抵御47吨冲击）
  - 战力：炼虚合道境界（平均），是13城最强陆军
  - 训练：每日13小时（体能+意识同步）

### 经济体系
- **GDP**：约47万亿神息币（军工占35%，重工业45%，服务业20%）
- **钢铁产量**：年约4.7亿吨（占13城总产量45%）
- **军工订单**：来自12城（主要供应符文武器和装甲）
- **信用系统**：
  - 日均交易：约47亿次（通过集体意识网络）
  - 信用分总量：约4,700万亿分
  - 流动性：每月约13%人口跨等级流动

### 社会结构
- **军工复合体系**：
  - S级（10万以上）：47,000人（特权阶层）
  - A级（1-10万）：470万人（精英阶层）
  - B级（1,000-10,000）：9,400万人（普通阶层）
  - C级（100-1,000）：4,700万人（底层）
  - D级（100以下）：380万人（罪犯和失败者）

- **等级固化**：
  - 出生决定70%人生轨迹（基因改造+家庭教育）
  - 跨等级流动率：13%/年（主要通过军工功绩）
  - 社会认同：87%居民认为"等级制度合理」

## 🏛️ 政治结构（2170年）

### 军事管理委员会（最高权力）
- **委员会**：13人（各垄断集团代表）
- **主席**：阿列克谢·马卡罗夫（时年87岁，钢铁巨子）
- **权力来源**：控制47%军工生产资源
- **与荀起元关系**：名义隶属，实际高度自治（每年提供47%产能作为"税贡」）

### 工业熔炉议会（执行层）
- **功能**：协调各企业生产，分配资源
- **成员**：47人（高级工程师和军工设计师）
- **特殊地位**：可否决军事管理委员会的决策（如果违背"钢铁意志」）

### 集体意识网络中心（控制层）
- **功能**：监控全民思想，协调生产，执行记忆净化
- **负责人**：神秘的"主脑」（实际是47名顶级意识黑客的集体意识）
- **特殊权限**：可强制修改D级人员记忆（每年约47,000人次）
