# 极夜城（Polar Night City）形成史

> 档案编号：HS-PN-2170
> 密级：公开（稷下学宫地理教材）
> 更新时间：2170年1月1日
> 备注：13城中最北端巨城，敖荒线索与慈悲杀戮之地

---

## 📍 基础信息

**地理位置**：原北欧北部，北纬78°13′N，东经15°33′E
**城市等级**：一级极寒巨城
**当前人口**：847万人
**占地面积**：9,800平方公里（含极光神殿）
**城市口号**："黑暗孕育光明，寒冷锻造意志"
**核心特色**：极寒生存 + 敖荒崇拜 + 慈悲杀戮传统

---

## 📜 形成时间线（2025-2170）

### 第一阶段：极地定居期（2025-2047）「寒冬堡垒」

#### 2025年：北极科研站扩建

```
背景：维度裂隙导致海平面上升，北欧多国联合开发北极资源
扩建计划：原挪威斯瓦尔巴群岛科研站升级为定居点
数据：初始人口4,700人（科研人员+矿工），年均气温-23°C
挑战：极夜持续47天（11月-次年1月），需要人工照明系统
技术突破：维度能量供暖（利用裂隙散逸能量，节能73%）
```

#### 2034年：极光神殿发现

```
发现者：极光观测员埃里克·瓦尔伯格（瑞典籍）
发现过程：在极夜期间观测到极光异常汇聚，形成"极光漩涡"
神殿位置：地下47米冰层中，天然冰洞形成
神殿特征：冰墙自然形成敖荒龙形图案，持续发光
影响：研究者发现敖荒线索，神殿被奉为"圣域"
保护措施：建立"守夜人"组织（最初47人），专职守护神殿
```

#### 2043年：文明城市

```
升格：人口达到847,000人，建设47条地下供暖通道
技术：极光神殿能量覆盖全城，维度稳定指数9.7/10
特色：培养出"寒冰体质"（居民对低温抗性提升，炼化寒气为神息）
产业：极光能源开发、极地修行、冰晶武器制造
```

### 第二阶段：敖荒线索期（2048-2079）「黑暗启示」

#### 2056年："黑暗日"现象

```
事件：极夜延长至87天（正常47天），极光神殿爆发强光
现象：居民在黑暗中看到"敖荒游弋"幻象（龙形虚影在天空游动）
发现：黑暗环境能大幅提升修炼速度（3.7倍），尤其是敖荒之力
传承：埃里克发现敖荒种子（在神殿冰核中），后传给杨守诚
```

#### 2067年：慈悲杀戮传统确立

```
起因：资源匮乏，重病患者痛苦求死
首次执行：埃里克为妻子执行慈悲杀戮（用极光冰刃，无痛苦）
仪式化：形成传统，每年极夜期间，为47名绝症患者执行
意义："在黑暗降临前，给予最后的尊严"
杨守诚学习：2164年在此学习慈悲杀戮技艺，后成为杨无尘技能
```

#### 2078年：杨守诚的极夜修行

```
修行时间：2164年11月-2165年1月（完整极夜周期）
导师：埃里克（时年137岁，极光神殿守护者）
学习内容：黑暗孕育可能性、敖荒视界、慈悲杀戮
获得物品：极光冰刃（后传给杨无尘）、敖荒鳞片（13片）
预言："杨无尘将在2170年重来，领悟真正的黑暗与光
```

### 第三阶段：现代（2080-2170）「守望时代」

#### 2170年现状：

```
人口：847万人（增长缓慢但稳定）
修炼特色：47%居民炼虚合道境界（极寒锻造意志）
极光神殿：每日13,847人参拜，祈求敖荒祝福
特色产业：极光能源出口（占城市GDP的47%）
```

#### 2170年12月？：杨无尘到达

```
到达背景：调查爷爷失踪，领悟黑暗与可能性
关键事件：
  - 在极光神殿完成47小时冥想，觉醒敖荒种子
  - 理解"黑暗孕育可能性"（第200章核心突破）
  - 执行第一次慈悲杀戮（救387名被虚无侵蚀者）
  - 获得"烛龙之眼"（夜视能力，黑暗中视物如昼）
```

### 核心数据（2170年）

**基础设施**：
- 极光神殿：高147米，13层，可容纳47,000人
- 供暖系统：47条地下通道，总长度1,470公里
- 极光能源：年产量47亿千瓦时（供应13城）

**人口与经济**：
- 人口：847万人（自然增长率1.3%）
- 修炼水平：炼虚合道占47%，炼道成仙占0.73%
- 极光猎手：147,000人（专职狩猎极光兽，提取能源）
- 守夜人：47,000人（守护神殿与城市）

**军事力量**：
- 极光守卫军：87,000人（炼虚合道境界）
- 装备：极光冰甲（可抵御-147°C）、敖荒战刃
- 特殊能力：黑暗适应（极夜期间战力提升47%）

**文化特色**：
- 慈悲杀戮：每年极夜为47名绝症患者执行（神圣仪式）
- 敖荒礼拜：每月13日，47,000人同步冥想
- 极光庆典：极夜结束日，全城狂欢47小时

### 政治结构

**议长制**：埃里克（极光守护者，兼任议长）
**守夜人议会**：47名长老（必须在极夜中冥想47天才能当选）
**特殊地位**：不接受维克斯统治（独立，但承认13城联盟）

### 关键人物

**埃里克·瓦尔伯格**：极光守护者（190岁，生理年龄73岁）
- 杨守诚的师父，杨无尘的师祖
- 掌握完整的敖荒黑暗修炼法
- 2174年将传位给杨无尘（成为新一极夜城主）

**极光祭司团**：47人（专职解读敖荒神谕）
- 能预测维度波动（准确率73.4%）
- 2171年协助杨无尘预判卡俄斯行动

### 与主线关系

**杨守诚**：2164年在此学习47天，获得敖荒认可
**杨无尘**：2170年来此领悟黑暗，突破炼气化神境界
**云裳**：2171年来此接受后土-敖荒融合指导
**卡俄斯**：2173年试图入侵极夜城，被极光神殿击退

### 城市未来

**2171-2175年**：
- 成为对抗卡俄斯的前哨站（维度波动最敏感）
- 杨无尘黑暗修炼的基地（每年返回修炼）
- 极光能源支持13城联盟战争（能源供应）
- 2174年埃里克去世，杨无尘接任城主
