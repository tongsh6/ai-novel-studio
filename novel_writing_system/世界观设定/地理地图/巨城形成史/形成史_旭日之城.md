## 📍 基础信息

**地理位置**：原东亚沿海地区，北纬31°14′N，东经121°29′E
**城市等级**：一级巨城
**当前人口**：1.2亿
**占地面积**：9,500平方公里（含地下区）
**城市口号**："光暗相生，平衡永恒"
**核心特色**：敖荒崇拜中心 + 光暗平衡哲学 + 维度交汇点

## 📜 形成时间线（2025-2170）

### 第一阶段：觉醒期（2025-2055）「光暗同源」

#### 2025年：维度裂隙异常预警
```
事件：东海沿岸观测到第一次维度裂隙异常波动
地点：原华东地区沿海观测站
数据：
  - 裂隙能量等级：0.87特斯拉（异常值）
  - 波动频率：11.3赫兹（非自然频率）
  - 持续时间：约47分钟
  - 影响半径：直径3.2公里
初期发现：
  - 裂隙周围出现"白昼如夜"现象（持续时间23分钟）
  - 当地247名居民出现集体性"双重记忆"症状
  - 受影响人群在黑暗中能看到微弱光点（后被证实为维度碎片）
```

#### 2038年：敖荒意志的首次显现
```
关键人物：沈清澜（时任维度异常调查组组长，时年41岁）
事件经过：
  - 在裂隙核心区失踪173小时（约7天零5小时）
  - 返回时携带一枚发光的维度碎片（后被命名为"旭日之核"）
  - 声称在裂隙中"听到了光的低语"（敖荒意志雏形）
后果：
  - 建立"光暗研究观测站"（后发展为旭日之城科学院）
  - 招募首批428名"光之学徒"（第一批居民）
  - 开始在裂隙区域建设永久定居点
技术突破：
  - 学会利用维度碎片产生稳定光源（替代传统电力）
  - 发现黑暗环境能加速修炼（黑暗孕育可能性理念雏形）
```

#### 2055年：光暗平衡哲学体系建立
```
核心文献：《光暗同源论》（作者：沈清澜，时年58岁）
主要思想：
  - 光暗不是对立，而是同一本质的两种表现
  - "在至暗之处，方能见到最纯粹的光"
  - 修炼者必须同时接纳光与暗才能达到平衡
基础设施建设：
  - 建造"永恒曙光塔"（高度487米，32层）
  - 围绕塔身建立环形居住区（首批容纳14.7万人）
  - 挖掘地下暗区（深度127米，用于特殊修炼）
人口规模：
  - 常驻人口：38.9万人
  - 流动修炼者：约5.2万人/年
  - 核心研究员：1,847人
```

### 第二阶段：扩张期（2056-2098）「旭日东升」

#### 2061年：第一次"暗夜日"现象
```
事件：全城范围内的24小时完全黑暗
现象特征：
  - 时间：2061年12月23日 06:14至次日06:14
  - 范围：覆盖整个旭日之城及周边11.3公里区域
  - 异常：太阳"熄灭"，但城市内所有光源增强300%
  - 无人员伤亡，但43,281名市民经历"记忆回溯"
关键发现：
  - 沈清澜证实这是"敖荒的呼吸"（维度自然波动）
  - 在黑暗中，129名儿童觉醒特殊能力（光暗双修体质）
  - 地下暗区的维度碎片产生共鸣，形成"暗之泉"现象
灾后重建：
  - 建立"光暗预警系统"（预警准确率78%）
  - 扩建暗区，建造"永夜之城"（第二居住区）
  - 开始接受其他城市的"暗之适格者"移民
```

#### 2079年：维度交汇点认证
```
认证机构：稷下学宫（前任宫主云苍考察）
考察数据：
  - 维度稳定性指数：8.7/10（13城中最高）
  - 修炼速度提升：平均3.2倍于其他城市
  - 异常事件发生频率：0.011次/年（极低）
  - 人口自然觉醒率：0.87%（普通城市的4.3倍）
特殊现象：
  - "光之桥"现象：每月初一，15%的居民能短暂感知其他维度
  - "暗之卵"孵化：每季度产生3-5枚维度碎片（城市核心资源）
  - 平衡者体质：每万人中约有1-2人天生具备光暗调和能力
官方认定：旭日之城为"13城中最适合修炼的城市"
```

  - 核心研究人员：12,847人

#### 2151年："呼吸之日"定位
```
定位原理：
  - 基于敖荒意志的维度波动周期
  - 每间隔11个月零23天，会出现"呼吸"现象
  - 呼吸期间，维度稳定性降至3.2，但修炼速度提升8倍
实际应用：
  - 守夜人部队在此期间巡逻频率提高3倍
  - 光暗双修学院安排高强度修炼课程
  - 圣殿开放"极限试炼"（死亡率上升至4.7%，但突破成功率27%）
关键数据：
  - 2151年周期：11月23天（首次精确预测）
  - 2152年周期：11月23天零47分钟（修正版）
  - 2153年周期：稳定在11月23天零12分钟
```

#### 2164年："平衡者"系统危机
```
危机起因：平衡者体质者数量异常增长（从0.01%增长至0.47%）
危机表现：
  - 觉醒者无法控制光暗调和能力
  - 14起"光暗暴走"事件（造成389人伤亡）
  - 暗之泉产生反向污染（光明区出现暗斑）
应对措施：
  - 沈清澜发布《平衡守则》（13条核心戒律）
  - 建立"光暗隔离区"（隔离异常觉醒者）
  - 圣殿增设"平衡试炼"强制通过率降至4.7%
结果：
  - 87名平衡者被强制休眠（等待"合适时机"）
  - 暗之晶核全部封存（共收集47枚）
  - 城市进入"平衡管制期"（持续到2172年）
```
