## 🏛️ 第一层：世界中央政府（World Central Government）

### 1. 维克斯科技集团（Vex Technologies Group）

**基本资料**
- **全称**: 维克斯科技-政府联合集团
- **性质**: 名义上是企业，实际是披着公司外衣的世界政府
- **总部**: 新京理性之塔（共1984层，天穹区以上108层为浮空岛）
- **创始人 & 终身最高理性者**: 荀起元（133岁）
- **口号**: "计算一切，优化一切」
- **财力**: 控制全球67%以上的量子计算资源、89%的意识科技专利

**组织架构**

```
荀起元（最高理性者）
│
├─ 天穹议会（7人核心决策层）
│   ├─ 首席技术官: 步父（步青霄之父，67岁）
│   ├─ 首席执政官: 叶卡捷琳娜（荀起元妻子，61岁，列宁格勒派系）
│   ├─ 首席财务官: 南山区（量子经济学家，58岁）
│   └─ 4名其他派系代表
│
├─ 13城执政官联席会议（名义上的市长，实际受维克斯控制）
│
├─ 中央职能部门
│   ├─ 意识科技研究院（ATRI）
│   ├─ 维度探索局（DEB）
│   ├─ 资源分配署（RDA）
│   └─ 净化部队总部（PFHQ）
└─ 全球分支机构
    ├─ 差分机运维中心（全球67个）
    └─ 基因优化站（每个巨城至少3个）
```

**意识形态：新世界主义**

核心教义:
1. **技术理性至上**: 所有问题都是计算问题，所有解决方案都是优化方案
2. **意识集中**: 人类意识应该像计算资源一样集中管理
3. **古神降临**: 古神（高维存在）的降临是文明跃迁的必要条件
4. **完美主义**: 不完美就是犯罪，缺陷必须被清除

**荀起元的个人哲学演变**:
- **青年期（2040-2060）**: "我要用技术创造一个公平的世界」
- **成熟期（2060-2100）**: "公平需要牺牲，为了整体必须牺牲个体」
- **现在（2100-2170）**: "人类本身需要被优化，古神将指引我们」

**2170年主要目标**:
- 重启新世界计划（因2138年云山之乱暂停）
- 寻找4417号实验体（杨无尘）
- 准备应许之城献祭仪式（预计2180年）

**内部矛盾**:
- ⚠️ 步父对儿子的系统故障表示担忧，但不敢公开质疑
- ⚠️ 叶卡捷琳娜与荀起元在"献祭规模」上有分歧（她认为3500万太多）
- ⚠️ 4名派系代表中有2人已被红莲教渗透

### 3. 红莲教（Red Lotus Society）

**基本资料**
- **名称**: 红莲教（又名"情感救赎会」）
- **成立时间**: 2103年（魔都地下）
- **创始人**: 墨竹的母亲（前维克斯工程师，已故）
- **现任领导人**: 赤鸦（代号，真实身份未知）
- **总部**: 魔都地下第67层（代号"火莲心」）
- **口号**: "在冰冷的世界里，燃烧最后的温度」
- **成员规模**: 约50万（核心成员5万，外围支持者45万）

**组织结构**

```
赤鸦（教主，精神领袖）
│
├─ 四神使（四大地区负责人）
│   ├─ 东神使: 墨竹（负责情报与网络）
│   ├─ 西神使: 索罗斯（负责资金与政治）
│   ├─ 南神使: 未知（负责外围区）
│   └─ 北神使: 未知（负责休眠区）
│
├─ 七莲座（战术指挥层）
│   ├─ 火莲座: 墨竹兼任
│   ├─ 水莲座: 柳莺儿（负责医疗与救援）
│   ├─ 风莲座: 前空军飞行员
│   ├─ 地莲座: 前地质学家
│   ├─ 雷莲座: 前电气工程师
│   ├─ 冰莲座: 前黑客
│   └─ 暗莲座: 前意识净化部队成员（叛逃）
│
└─ 红莲众（基层成员）
    ├─ 战斗组: 约1万人
    ├─ 情报组: 约3万人
    ├─ 医疗组: 约5千人
    └─ 后勤组: 约5千人
```

**意识形态：情感救赎主义**

核心教义:
1. **情感是人的本质**: 理性是工具，情感才是目的
2. **痛苦的价值**: 痛苦、悲伤、愤怒都是人性的证明，不应被消除
3. **集体意识不是幸福**: 失去自我的集体是监狱，不是乌托邦
4. **红莲象征**: 在灰烬中绽放，在绝望中燃烧

**核心经典**:
-  **《红莲经》**  （创始人墨母留下）: 用诗歌形式写成，引用波德莱尔、策兰、本雅明
-  **《情感防御手册》**  : 教导如何在意识监控下保护情感
-  **《地下诗集》**  : 收集全世界被禁止的诗歌、音乐、艺术

**主要活动**:
- **意识防火墙**: 为成员提供免费意识保护，抵抗认知审计
- **地下网络**: 运营独立于维克斯的量子通信网络（暗网）
- **医疗救援**: 为底层民众提供基因疾病治疗（合法医疗无法覆盖）
- **文化保护**: 保存被禁止的艺术、文学、音乐
- **武装抵抗**: 偶尔对维克斯设施进行破坏，但主要目标是"唤醒」而非"摧毁」

**资金来源**:
- **索罗斯**: 魔都执政官，提供50%资金，他相信"颠覆系统必须用钱砸」
- **黑市交易**: 梦境走私、记忆交易、基因技术改造（非法但利润高）
- **成员捐赠**: 许多外围支持者自愿捐赠收入的10%

**2170年状况**:
- **墨竹**正在调查父母失踪真相，发现与2128年维度共振事件有关
- **柳莺儿**负责魔都底层医疗点，她的基因缺陷越来越严重，但仍坚持工作
- **赤鸦**很少露面，通过加密量子场远程指挥，有传言说他是"第一代觉醒者」
- **组织面临分裂**: 温和派（墨竹）主张细水长流，激进派主张暴力革命

**重要据点**:
- **魔都67层**: 核心总部，防御等级极高，位置不断变动
- **红莲医院**: 柳莺儿负责的地下医疗点，表面上是废弃仓库
- **灵魂股市**: 索罗斯控制的合法机构，实际为红莲洗钱
- **记忆教堂**: 保存被删除的记忆碎片（包括被优化者删除的亲情记忆）

**未来潜力**:
- 🔗 **连接点**: 墨竹父母的意识备份可能在某个差分机深处，等待被唤醒
- 💡 **创意点**: 赤鸦可能是"情感聚合体」——由数千人的集体情感形成的新生命
- ⚠️ **待探索**: 红莲教的最终目标是什么？仅仅是反抗，还是有更大的使命？

### 4. 寂静山门（Silent Mountain Gate）

**基本资料**
- **名称**: 寂静山门（又称"蜀山遗脉」）
- **历史**: 传承自2138年前的蜀山派，是云山望岳最后的传承地
- **当前领袖**: 云山望岳（165岁，已失踪）和代理掌门**云裳**（18岁）
- **总部**: 蜀山禁区边缘，后山禁地（哈迪斯之躯封印处）
- **宗旨**: "守心如山，万念不入」
- **规模**: 核心弟子3000余人，外围支持者约20万

**组织结构**

```
师祖: 云山望岳（精神领袖，失踪状态）
│
代理掌门: 云裳（实际管理者）
│
├─ 七代弟子（老一辈，云家班底）
│   ├─ 大师兄云河: 已叛逃维克斯，实为卧底（负责4417号实验）
│   ├─ 二师姐云竹: 驻守山门，负责教学
│   ├─ 三师兄云河: 执行卧底任务
│   ├─ 四师兄云风: 云裳的保护者
│   └─ 五师姐云烟: 负责对外联络
│
├─ 八代弟子（中生代）
│   └─ 执法堂、藏经阁、后勤部
│
└─ 九代弟子（新生代，含杨无尘）
```

**传承体系**

**核心功法**:
1. **望岳九式**（云山望岳毕生绝学）:
   - 前三式: 炼精化气（筑基）
   - 中三式: 炼气化神（明心）
   - 后三式: 炼神化虚（悟道）
   - 最后一式: 望终式（未完成）
2. **地母心经**（云裳母亲留下）: 后土一脉传承
3. **静心咒**（基础功法）: 抵抗意识污染

**独特之处**:
- **拒绝基因优化**: 坚持自然修炼，认为"慢才是快」
- **意识防火墙**: 传统功法可以抵抗差分机侵蚀
- **师徒传承**: 强调"心法」而非"算法」

**2138年云山之乱后的变化**:

**云山的"失踪」**:
- 官方: 云山望岳在中洲悬崖战死
- 实际: 坠入哈迪斯封印区，意识被"粉碎」但碎片不灭
- 他在封印中以"量子幽灵」状态存在，偶尔能传递信息
- 只有云裳（后土化身）能听到他的"低语」

**山门的转型**:
- 从公开门派转为地下抵抗组织
- 从修炼教学转为培养"火种」
- 核心弟子必须同时进行"传统修炼」和"现代战术训练」

**2170年状况**:
- **云裳**担任代理掌门，但她18岁，缺乏威望
- 老一辈不服: "一个女娃，如何能继承望岳？」
- 但云裳展现出惊人的"大地感知」能力，能预知地震、禁区扩张等
- 她独自承担着保护后山封印秘密的的重任

**核心秘密**:
- 后山封印的是哈迪斯之躯，也是云山望岳的"半个身体」
- 杨无尘是4417号实验体，这个秘密只有云裳和云河知道
- 门派的最终使命: 等待"可能性之子」成长，然后协助他完成弑神

**重要据点**:
- **后山禁地**: 哈迪斯之躯封印处，量子场混乱，只有云裳能平静进入
- **藏经阁**: 保存着所有传统功法，包括禁忌的"源流武学」手稿
- **云裳的小屋**: 位于一棵千年古树下，是杨无尘童年唯一感到"平静」的地方

**未来潜力**:
- 🔗 **连接点**: 云山望岳的"量子幽灵」可能在关键时刻指引杨无尘突破境界
- 💡 **创意点**: 山门可能是敖荒留下的"种子库」——保存着人类未被污染的可能性样本
- ⚠️ **待探索**: 如果云裳是后土化身，她是否需要"牺牲」自己来稳定大地，对抗虚无？

### 5. 稷下学宫（Academy of Forgotten Science）

**基本资料**
- **名称**: 稷下学宫（又名"流亡科学家联盟」）
- **成立时间**: 2138年云山之乱后
- **创始人**: 谷父（谷沐霖之父）和67名叛离维克斯的科学家
- **当前领袖**: 学术委员会（7名首席教授轮值）
- **总部**: 移动式量子隐形实验室（位置不固定，每67天转移一次）
- **宗旨**: "用科学守护人性，用数据证明情感」
- **规模**: 核心成员500人，外围支持者约20万，大多是学术界良心

**组织结构**

```
学术委员会（7席）
│
├─ 认知科学部: 谷父担任首席
├─ 量子物理部: 王教授（前差分机首席工程师）
├─ 生物基因部: 李教授（基因编辑伦理审查委员）
├─ 社会心理部: 周教授（被维克斯开除的意识审计师）
├─ 哲学伦理部: 陈教授（古典哲学研究者）
├─ 网络信息部: 白教授（黑客身份）
└─ 历史档案部: 赵教授（新世界的记录者）
│
└─ 三等学士（研究员等级）
    ├─ 一等学士: 谷沐霖（最年轻的）
    └─ 二等、三等学士约500人
```

**核心主张**

 **《人性常量三定律》**  （谷沐霖提出，2138年）:

定律一（不可计算性）:
> 情感、直觉、创造力中存在无法被量子场模拟的"常量」
> 这些常量不是"误差」，而是人性的本质

定律二（价值不对称性）:
> 计算的效率与情感的价值不存在换算关系
> 1个真实的拥抱 > 1000次虚拟的快感

定律三（反抗必然性）:
> 任何试图完全控制人性的系统，都会催生不可预测的反抗
> 这种反抗不是bug，是feature

**主要成就**

1. **意识防火墙**:
   - 开发出"差分机无法识别」的加密方式
   - 使用"人性常量」作为密钥，机器无法破解
   - 为红莲教和其他反抗者提供通信安全

2. **基因污染净化**:
   - 发现"强制基因编辑」的代际累积效应
   - 为受迫者提供"基因债务修复」治疗
   - 柳莺儿是第一批接受治疗者（但效果有限）

3. **历史档案保存**:
