# B90 · 应用侧排版能力与模型工具调用闭环

**状态**：**todo（2026-11-25 规划登记；尚未实施或验收）**。独立排期，优先级低于 B91；不作为 B87 完成前置。唯一执行状态源为本文件，排期见 [NEXT](../NEXT.md)。

## 1. 来源、目标与范围

作者于 2026-11-25 明确：排版不是核心价值，若继续解决应单独起 slice；应用提供可靠能力给模型调用。同次讨论确认另起 [B91](B91-agent-turn-step-execution.md) 处理多轮多步和局部两次限制。本任务继承 [ADR-0029](../../docs/design/adr/ADR-0029-prose-formatting-plan-v3.md) 与 [B28](B28-whole-chapter-revision.md)，承接 [B87 §28](B87-model-interaction-request-projection.md#28-排版与多轮多步的独立承接2026-11-25) 中 P2 的排版产品交付目标。

作者提出“只调整分段和排版，不改字句”，能够得到真实变化的预览，采纳后形成正确章节的新版本，阅读与重新打开一致。需要语义判断的分段位置可由模型选择；原文变换、字节保真、版本保护与事务由应用保证。明确的机械操作由应用确定执行，不要求模型重新抄写整章。

首个范围沿 ADR-0029：只改变受授权位置的 CR/LF，全部非换行字节（字句、标点、空格、Unicode 组合与顺序）不变。没有实际变化时诚实说明，不为凑成功制造改动。是否需要简化现有工具包装，由 CP0 的真实消费者审计决定，不预设新增工具或字段。

不扩展为出版排版系统、通用编辑器或文本处理框架；不润色或改写，不另建候选、采纳、权限、预算、历史或证据体系。运行循环由 B91 承接，通用意图、来源、目标消歧和作者可见内容职责仍按 B87 保留范围核定。

## 4. Checkpoint 与完整 DoD

| CP | 工作 | 结束条件 |
|---|---|---|
| CP0 | 核 ADR-0029 → 真实工具目录/请求 → 计划 → 应用 → 采纳 | 明确应用缺口、模型调用负担、最小工具契约和消费者；不把 P2 协议拒收误判为算法缺失 |
| CP1 | 在现 owner 内修正已证明的耦合/调用负担及可操作反馈 | 真实入口使用可靠应用能力，无排版特例预算和平行状态 |
| CP2 | 预览、采纳/放弃、同章版本、阅读、维护、重开及异常 | 全链机制和原生页面成立，内容/对象/版本/采纳保护无回归 |
| CP3 | 固定真实输入、源、模型配置、运行预算并取得真实调用证据 | P2 与必要独立对照达成作者目标；适用工程门与分组交付完成 |

全满足才可改为 done：

1. 模型实际调用应用能力；正文由原文和确定性操作形成，不由模型抄写整章。
2. 需要改变时产生符合要求的分段；无需改变时准确反馈。非选定位置换行和全部非换行字节保持原样。
3. 参数损坏、未知/重复边界、非法行数、错作品/错章/缺来源均给准确反馈且不写入。
4. 预览后源变化、版本过期、preview hash 不符、事务失败得到拒绝或回滚；重复采纳不重复产生效果。
5. 模型说明与应用预览分离；采纳作用于正确同章版本，历史、阅读、重开及必要摘要/账本维护一致。
6. 真实模型、确定性机制、真实页面各有证据，互不代签；适用 AGENTS/quality-gates 门禁、引用和可审查提交完整。

必须覆盖：模型偷偷改字/标点/空格/Unicode；只改说明但计划无效果；重复句选错位置；局部材料冒充全章；旧源边界；预览后并发修改；未采纳写正文；说明进入作品记忆。最小 checkpoint 不缩小上述完整闭环。
