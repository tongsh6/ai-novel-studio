# R04 — 判断阶段最小可信 Base（移除无关大正文）：一次独立 AI 编码会话执行指令

## Goal（唯一交付目标）
在不预判用户语义的前提下，判断阶段默认提供必要权威事实和对象身份，而非完整角色档案、候选正文和多份历史全文。

## 上游前置条件（不满足不得开工）
R03；必须通过 R00 审定的不可省略 Base 最低集合。

## 范围与不可变边界
**允许**：优先 JudgmentProtocol 的 scope 组装、当前 ContextAssembler/DialogueContext 的投影出口及对应 judgment context tests；只改首个判断消费者。

**禁止**：不新增关键词路由、意图分类 Router、不删除必要对象 refs/权限、不强制 writer/修订器复用判断阶段的瘦上下文。

## 执行计划（必须在本会话完成）
1. 定义判断阶段的必带集合：作者原话、作品/会话身份与当前权威版本、必要章节索引/统计、合法身份 refs、工具目录/预算/权限。
2. 长角色说明、resolved/pending 历史 body_preview 与正文改为摘要/引用入口（如当前任务确需，应按现有探索工具读取）；保持可发现性。
3. 对“当前章数”和“已有角色改成主角/改已有候选/章节修订”场景分别验证：第一类少读，后几类可取回所需身份/全文，不要求作者重新提供系统已有事实。
4. 使用 R01 统计 before/after：少了什么，有什么证据，是否出现错误遗漏。

## DoD（必须全部满足）
- [ ] 简单统计请求不含无关长角色全文/候选全文；必要 refs 未丢。
- [ ] 已有对象修订、待采纳候选、非唯一目标、跨作品隔离保持原行为。
- [ ] 真正需要全文的请求能经授权只读探索补足；不编造内容。
