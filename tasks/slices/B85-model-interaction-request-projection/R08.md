# R08 — 专业创作链不退化回归：一次独立 AI 编码会话执行指令

## Goal（唯一交付目标）
确保瘦化判断上下文与历史压缩不会破坏真正需要完整正文、章计划、人物状态和作者风格的创作链。

## 上游前置条件（不满足不得开工）
R03–R07 已通过；现有作品/修订/作者原文/质量契约为准。

## 范围与不可变边界
**允许**：以现有 writer/prose revision/quality 入口及测试为主，新增端到端机制夹具和小范围回归修复；如果发现较大独立缺陷，创建单独任务，不在本批展开新功能。

**禁止**：不重构 Writer、不更换小说质量算法、不新增作者资产系统、不以压缩/summary 代替整章修订的必要全文。

## 执行计划（必须在本会话完成）
1. 验首稿、续写、指定片段修订、整章修订、纯排版、角色已有档案修改、缺证据取证，覆盖作者限制/版本/对象一致性。
2. 检验 writer 实际接收到目标正文及完整基线（需要全章时不能只用片段），未采纳产物不污染 canonical。
3. 对作者素材/文风所需事实仅验证存在按需扩展路径，不在此实现 Issue #3。
4. 将确认的回归问题限定于此次 Context Projection 引入的差异，修复和场景一同提交。

## DoD（必须全部满足）
- [ ] 所有专业创作入参保持完整性、来源、范围及作者原话字节。
- [ ] 现有 prose writing / revising / quality / adoption tests 通过，0 个未授权写入。
- [ ] 不存在用短摘要或单段冒充完整章节修订。
