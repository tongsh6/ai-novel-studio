# R07 — 讨论、纠错、明确行动的语义判界：一次独立 AI 编码会话执行指令

## Goal（唯一交付目标）
避免作者只是讨论时模型过早调用能力缺口/动作，同时在作者明确授权目标时能够继续执行或准确报告缺口。

## 上游前置条件（不满足不得开工）

## 范围与不可变边界
**允许**：优先 AuthoringTaskPolicy、既有 JudgmentProtocol / TurnInteractionService 的当前判别语义与相关测试；只改已经证明确有冲突的规则。

**禁止**：禁止新增 if/contains 语句专门识别“卷纲”等词、硬编码某个用户或小说输入；禁止为通过某一场景削弱其他创作请求。

## 执行计划（必须在本会话完成）
1. 将“章状态是否完成”与“文学意义写完了吗”分开；提供事实分类和必要取证边界，不重复冲突判例。
2. 建立最小对比语义矩阵：事实询问、结构异议/讨论、明确效果请求、条件句否定、明确生成、缺信息、缺能力。
3. 用同一真实上下文测三轮判界；讨论回合只回复，明确要求缺能力时报告缺口；不检查未读正文就宣称质量已通过。
4. 确定性机制测试之外，实模质量单独记为待 R09 复证，不用 stub“证明模型真正理解”。

## DoD（必须全部满足）
- [ ] 针对用户真实三轮输入的决策语义不发生误升级。
- [ ] 其它负例、已有候选修订/作者明确生成/作者只说“先收下”不发生回归。
- [ ] 系统层仍不预先声明模型应当认为的具体意图。
