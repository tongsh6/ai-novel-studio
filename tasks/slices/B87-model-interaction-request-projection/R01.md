# R01 · 模型请求/响应成本与语义的可靠基线

> **唯一目标**：对真实三轮和可重复多轮场景给出同口径、可审计请求分组/性能/模型判断基线；不先优化
> **状态真源**：[B87 总计划](../B87-model-interaction-request-projection.md)，本卡不记录 PASS/done；[通用单会话协议](README.md) 必读。

## 开工前置
R00 事实地图；真实 Provider 调用/JSONL 或可信日志必须合法取得，不把示例数据伪装实际已发生请求。

## R00 冻结的输入与读侧

- **A（真实样本）**：同一 work/session 的真实 Tauri 作者连续三轮输入；按实际 Provider call、turn、session 分组，保留工具调用与最终作者可见结果的关系。Provider/model/推理配置沿用已明确授权的预注册范围；授权不覆盖本次调用时先确认，不自行外推。
- **B（压力样本）**：以 A 冻结的 RequestIR/消息序列为种子，固定 seed 构造 3/10/20 轮；显式覆盖 Scope 更新、闭合/未闭合 tool exchange、observation/ref 和正文基线。B 是 synthetic，只测确定性投影/字节/Token/前缀增长，不伪造 Provider usage；未发真实请求时 TTFT、latency、cached_tokens 均为 `not_collected`。
- **实际 wire 读侧**：`NovelTelemetry.LLMLog` JSONL（`log/llm-calls/YYYY-MM-DD.jsonl`）是精确 request/response body 来源；`ProviderRunLog`/`ProviderOutputRecord` 只交叉核对 run、usage、duration、refs；`RequestIR`/`RequestIR.Projection` 是确定性重建对照，不冒充实际 wire。
- **隐私**：原始 JSONL 可能包含作者原文，不能提交 Git 或上传 Actions artifact。报告只保存 source/hash、字节/Token 计数、provider/model/options、refs、延迟与必要脱敏分类；cached_tokens 是 input_tokens 子集，不相加。
- **当前阻塞**：R00 核查的 GitHub HEAD 不包含既有 stage JSONL 或 B71 ignored 预注册 artifact。未取得可访问的真实三轮样本前，R01-A 保持 BLOCKED；不自行生成或虚构真实输入。R01-B 的压力构造可以先准备，但不得替代 A。


## 当前批次的职责边界
仅测试/诊断脚本、质量 fixture 和证据文档；禁止生产 Prompt、IR、Provider 的行为改动。

## 完整执行步骤（一个会话必须交付）
1. 从真实 Provider 请求或统一 RequestIR 提取按 System/Tools/Scope/History/Observation/Writer 材料分类的精确字节和可得 Token，保留 source/hash/版本。
2. 冻结三轮真实作者输入与 3/10/20 轮压力构造，分别记录 tool call 与最终作者可见结果，避免把旧异常标为正常。
3. 记录 input_tokens、cached_tokens（输入子集）、output、TTFT、延迟、Provider、model、推理选项、prefix hash、场景覆盖与样本噪声。
4. 输出 BEFORE 仪表/机器可重算 manifest 和负例，后续各批沿用同源口径。

## 反例与禁止行为
不能把 cached_tokens 与 input_tokens 相加；不能以首次请求低成本掩盖跨轮增长；无真实用量时标 not_collected。

## DoD（全满足才 PASS）
固定测试种子/输入、无清洗敏感原文泄漏的报告、可重复运行命令与单位；不宣称已达到优化目标。

## 真实用户效果与证明
至少能指出旧 Scope 第几轮重复、真实 Base 与 Observation 来源；只证明测量入口，不签模型行为改善。
