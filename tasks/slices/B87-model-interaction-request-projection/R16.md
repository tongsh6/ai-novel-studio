# R16 · Smart 模式的可重算安全策略与保守回退

> **唯一目标**：Smart 不是让模型凭感觉自授权限，必须给出可审计的规则、确定性输入与未知态回退
> **状态真源**：[B87 总计划](../B87-model-interaction-request-projection.md)；本卡只承载当前会话执行契约，[README](README.md) 为全部批次共享门禁。

## 开工前置
R10–R15 全通过；VS-00M 已定义 smart 候选体验，实际规则需核实用户收益与已有策略是否足够。

## 真实改动范围
复用现有风险派生/授权模式/委托检查，不引入子 Agent 风险评估、独立 rule-engine 或隐式可写学习器。

## 一次会话内必须执行的完整步骤
1. 明确 smart 的唯一策略源：当前有效 user scope/风险等级/委托和已确认目标事实；编制可机械重算、含解释 reason_code 的决策表。
2. low 只读允许；medium 非写权威可生成 tentative；high 必须保守确认；critical 恒确认；缺身份、scope、证据或风险不确定时 deny/ask，不允许自动填规则。
3. 与 manual/risk_based/full 同一 authoritative gate 比较，smart 不得扩大用户未授予的范围；前端说明该模式实际会做什么。
4. 做一组属性测试与真实 UI 输入，覆盖更改上下文/对象/风险/会话继承/取消/复用旧授权/跨作品/版本变化。

## 反例与不可逾越的禁止项
不能增加第二模型来‘判断可信度’，不能以模糊 risk_hint 或 hardcoded 字符串做授权；未明确的智能决策一律保守失败。

## Definition of Done（不可打折）
Smart 在固定输入下多次产出同一决定，风险越高不越权，真实作者能解释并撤销结果；真实界面不宣称不可解释的智能授权。

## 作者真实使用场景与验收效果
作者可以使用比手动少打断但仍可预测的授权模式，而不是把判断权交给未知模型。
