# R11 · 授权模式优先级与持久化一致性

> **唯一目标**：明确表示 manual/risk_based/full/smart 的用户模式，保证 run > session > work > global 生效、到期/撤销/版本与恢复一致
> **状态真源**：[B87 总计划](../B87-model-interaction-request-projection.md)；本卡只承载当前会话执行契约，[README](README.md) 为全部批次共享门禁。

## 开工前置
R09/R10 已通过；先查 AgentRun.authority_scope、AgentRunPolicy、WorkSession/作品偏好/现有持久配置是否能承担模式层级；若确需新字段提供查重与契约证据。

## 真实改动范围
domain/application 已有纯政策与配置读取写入边界、最小必要 persistence；不新增独立全能权限服务或多表模式框架。

## 一次会话内必须执行的完整步骤
1. 清点现有用户设置/运行时配置/AuthorAction 输入/持久化字段，决定单一模式写入位置、来源 ref、scope、created_at、modified_at、revoked/expired。
2. 实现 run/session/work/global 明确覆盖与向下继承；删除旧隐式硬编码与无消费者字段，默认未配置为保守的现有安全行为。
3. 恢复/重启/会话切换/多作品/跨来源冲突/并发写/过期委托下正确重算 effective_mode、mode_source、version。
4. 用真实 Channel/API/现有设置消费者证明写入-读取-回放，权限模式只能由合法用户动作修改，模型不得自写。

## 反例与不可逾越的禁止项
不得创建只存模式名的独立 config 表而遗漏授权来源/撤销；full 作为 mode 本身不能伪造具体 delegation 权限。

## Definition of Done（不可打折）
持久模式跨重启/多层继承一致；错作品/过期/revoke 拒绝；现役 Gate 能消费真实有效值，负例均可回查。

## 作者真实使用场景与验收效果
同一个作者在作品/会话不同作用域设置后，系统展示的生效模式能与实际运行行为一致。
