## 完整执行步骤（一个会话必须交付）
1. 将冲突判例（是否写完的结构状态 vs 文学完成）、能力缺口与作者讨论、内容登记等收敛为单一无矛盾业务规则；已测有效案例不能无证据删除。
2. 按愿景、设计和本卡独立判据验证完整语义矩阵；原三轮真实作者原话保留为重要回归场景之一，验证第二轮自然讨论、第三轮按真实能力缺口或合法操作处理，不能以三轮通过代签本卡其余边界。
3. 新增修改已有候选、整章、先别动笔、只保存资料、缺来源、已明确目标、同名歧义等负例；模型只在需补知识时主动探索。
4. 对比同一真实模型与确定性机制，不能用 string.contains 路由和 stub 提升虚假通过率。
5. 局部章正文使用 `modification_scope=target_segments` 与 `items[].target_segment_ids`，核真实对象/当前作品、操作对应的已供材料、完整目标字节和版本/hash；目标领域 ID 不与 observation_ref 直接作字符串集合比较。source_refs 真实，观察 `coverage_note` 与实际材料一致；局部候选不得冒充全章；原 `rationale` 必须与原 `body` 的可观察改动一致。普通 artifact 继续采用其现完整对象修订合同，不套用章范围字段。
