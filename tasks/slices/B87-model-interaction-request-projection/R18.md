## 一次会话内必须执行的完整步骤
1. 以真实作品进行首稿、续写、多章回忆、角色状态、卷纲/章节边界、整章/目标段/纯排版修订、质量反馈与已采纳冲突回滚。
2. 使用 source_ref、accepted revision、完整正文覆盖和实际 writer 请求证明模型得到真实必需上下文；提示/未知正文不能冒充 complete。
3. 作者原始措辞、目标外正文、风格样本与 tentative/adoption 的字节因果各做正负例；错误时应保留可恢复状态而非生成‘看似完整’的段落。
4. 真实 Tauri 章节内容、候选选择、采用/拒绝/撤销与质量盲评样本分层执行，记录创作质量/作者负担结果，不以单元测试代签文学效果。

## 反例与不可逾越的禁止项
不牺牲人物逻辑/情绪推进以缩上下文；不为通过质量门拼凑禁用模型回执或删除失败语料。

## Definition of Done（不可打折）
关键专业创作行为无回归，整章修改不误用单片段，真实作者可见内容没有协议 UUID，权威事实无非法改变。

## 作者真实使用场景与验收效果
用户能正常写长篇且不被新交互结构损害原创表达与小说体验。
