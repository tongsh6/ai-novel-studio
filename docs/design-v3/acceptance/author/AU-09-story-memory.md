# AU-09 管理故事设定

> 作者视角：写了一段时间后，我的小说有了很多设定——角色关系、伏笔线索、世界观规则。我需要一个"故事圣经"来管理这些内容，能浏览、搜索、新增、修改，确保我的故事世界前后一致。

---

## 1. 我能做什么

| 我能做什么 | 系统怎么回应 |
|-----------|------------|
| 打开作品档案面板 | 看到作品总览（卷数、草稿数、角色数、设定数） |

| 看到待采纳的内容 | 可以直接在面板里"采纳"或"提出修改" |

#### S7 — 记忆状态流转

**作为作者**，我打开一条"草稿"状态的伏笔，确认它已经确定→点击"确认"。后续如果这条伏笔不再适用→点击"弃用"或"归档"。如果它是核心设定不希望被 AI 误改→点击"锁定"。

```
状态流转:
DRAFT → CONFIRMED → STABILIZED
                  → DEPRECATED → ARCHIVED
                  → CONFLICTED
锁定/解锁: 任意状态
```

**验证点**：
- [ ] `confirmMemory`：DRAFT → CONFIRMED
- [ ] `lockMemory` / `unlockMemory`：切换锁定状态
- [ ] `deprecateMemory`：标记为 DEPRECATED
- [ ] `archiveMemory`：标记为 ARCHIVED
- [ ] `updateMemoryWeight`：调整权重（影响 AI 回忆优先级）
- [ ] 每次操作后详情面板更新为新状态

**代码**：`MemoryDetailDrawer.tsx` + `memoryApi.ts` ✅
