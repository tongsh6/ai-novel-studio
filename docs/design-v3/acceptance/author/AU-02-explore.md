# AU-02 探索创作方向

> 作者视角：我有一个模糊的创作想法但还没想清楚，AI 应该像创作伙伴一样帮我展开思路、给出几个可能的方向，而不是丢给我一张必填表单。

---

## 1. 我能做什么

| 我能做什么 | 系统怎么回应 |
|-----------|------------|
| 说"我想写赛博修仙但没想好" | AI 给我 2-3 个方向，让我选口味 |
| 和 AI 来回讨论创作可能性 | AI 用自然对话帮我理清思路 |
| 看到候选方向 | 方向是讨论材料，不是正式设定 |
| 不想要了可以不管它 | 候选方向不会自动变成作品设定 |

明确不能做的：
- AI 不应该弹出一张表让我填"作品类型、主角身份、世界观、目标读者"
- 候选方向不能自动写入作品设定

---

## 2. 验收场景

### 场景组 A：自然探索

#### A1 — 模糊想法产生自然对话回应

**作为作者**，我输入一句"我想写一个赛博修仙，但还没想好方向。帮我想想可以怎么切入。"

```
作者: 我想写一个赛博修仙，但还没想好方向。帮我想想可以怎么切入。
AI: 这个方向可以有几种味道：公司垄断灵气、宗门搬进霓虹都市、
    修仙者被算法评级。你更想写热血、黑色幽默，还是压抑一点？
```

**验证点**：
- [ ] AI 的回应读起来像创作讨论，不像表单
- [ ] 回应中包含对不同方向的展开说明
- [ ] 没有出现"请补充以下信息"、"必填字段"等表格式语言

**测试**：`dialogue_gateway_test.exs` — `"fuzzy creative idea enters exploration frame"` ✅（验证 frame_type + decision_type）
**测试**：`dialogue_gateway_test.exs` — `"assistant message is natural exploration not field list"` ✅（验证不含"请补充以下信息"、"必填字段"）

---

#### A2 — 不会弹出机械表单

**作为作者**，我只是还没想好方向，AI 不应该丢给我一张表让我填。

**验证点**：
- [ ] 回应中不包含 `required_slots` 字段
- [ ] 回应中不包含 `missing_slots` 字段
- [ ] 回应中不包含 `slot_schema` 字段
- [ ] 回应中不包含 `slot_form` 字段
- [ ] 不会打开 durable clarification

**测试**：`dialogue_gateway_test.exs` — `"does not open mechanical slot form"` ✅

---

### 场景组 B：候选方向

#### B1 — 看到候选方向

**作为作者**，AI 在探索对话中给了我几个可选方向，每个方向有标题、简短说明和风格标签。

```
候选创作方向:
  ┌─────────────────────────────────────────┐
  │ 公司垄断灵气                            │
  │ 修仙界的灵气被几家巨头公司垄断，修仙者    │
  │ 变成了打工人，修炼资源按绩效分配。        │
  │ [热血] [黑色幽默]                        │
  └─────────────────────────────────────────┘
  ┌─────────────────────────────────────────┐
  │ 宗门搬进霓虹都市                         │
  │ 传统修仙宗门在现代都市中生存，用霓虹灯    │
  │ 广告招弟子，飞剑和悬浮车抢车道。          │
  │ [热血] [都市]                            │
  └─────────────────────────────────────────┘
```

**验证点**：
- [ ] 每个方向有标题（`title`）和说明（`pitch`）
- [ ] 有风格标签（`tone_tags`）帮助作者判断
- [ ] 候选方向在 TurnResult 中以 `candidate_directions` 呈现

**测试**：当前 stub provider 返回空 candidates，real LLM 才会产生候选方向。断言 `Enum.all?(candidates, & &1.adoption_status == :not_adopted)` ✅

---

#### B2 — 候选方向只是讨论材料，不是正式设定

**作为作者**，AI 给出的候选方向只是帮我想的，不应该自动变成我的作品设定。

**验证点**：
- [ ] 候选方向默认状态为 `not_adopted`
- [ ] TurnResult 不能声称"已创建作品"或"已采纳设定"
- [ ] TurnResult 的 `truthfulness` 中 `tool_called == false`、`artifact_adopted == false`

**测试**：`dialogue_gateway_test.exs` — `"candidate directions are marked not_adopted"` ✅
**测试**：`dialogue_gateway_test.exs` — `"does not claim tool/adoption/write/behavior"` ✅

---

### 场景组 C：持续探索

#### C1 — 可以基于候选方向继续追问

**作为作者**，我看到 2-3 个方向后，可以针对某个方向继续追问。

```
作者: "第一种方向（公司垄断灵气）挺有意思，能再展开一下吗？"
AI: 基于这个方向的进一步展开...
```

**验证点**：
- [ ] 后续消息能引用之前的方向讨论
- [ ] 不会因为追问而打开 durable behavior
- [ ] 每轮仍然是 exploration 或 casual_reply

---

#### C2 — 探索多轮后仍然可以自由文本

**作为作者**，我聊了 5 轮探索方向，第 6 轮我仍然可以用自由文本继续聊，而不是被限制在某几个 action 按钮里。

**验证点**：
- [ ] 探索阶段 `available_actions` 为空或只有 `continue_dialogue`
- [ ] 输入框始终可用，不强制作者点击 action 按钮

## 4. 缺口

| 缺口 | 影响 | 建议处理 |
|------|------|---------|
| GAP-01 — 持续追问场景 | 多轮探索的连贯性未验证 | 新增多轮对话测试：第1轮模糊输入→第2轮追问→验证上下文延续 |
| GAP-02 — 探索阶段不强制 action | 如果 available_actions 非空会阻塞自由文本输入 | 在探索路径中验证 available_actions 为空或仅 continue_dialogue |
