# AU-08 阅读我的作品

> 作者视角：经过和 AI 的多轮讨论、生成、采纳后，我有了真正的章节内容。我可以在一个干净的阅读模式里翻阅目录、逐章阅读，像看一本真正的书。当底层设定变更导致内容过期时，系统会提醒我刷新。

---

## 1. 我能做什么

| 我能做什么 | 系统怎么回应 |
|-----------|------------|
| 在工作台点击"阅读模式" | 切换到干净的阅读视图，展示目录和正文 |
| 浏览目录（TOC） | 看到分卷和章节结构，点击切换章节 |
| 阅读章节正文 | 看到场景分段、自然段落排版的正文 |
| 看到"投影已过期"提示 | 知道底层设定变更了，当前阅读的可能不是最新版 |
| 点击"刷新投影" | 系统重建阅读视图，展示最新内容 |
| 返回工作台 | 一键切回工作台继续创作 |

明确不能做的：
- 阅读模式不能修改正文（只读）
- 未采纳的草稿不应出现在阅读视图中

## 4. 验收场景

### 场景组 A：目录浏览

#### S1 — 有已采纳内容时看到目录

**作为作者**，我在工作台中采纳了一些章节后，切到阅读模式。左侧目录栏显示分卷和章节结构。

```
阅读模式:
┌─ 目录 ─────────────────────┐  ┌─ 正文 ──────────────────────┐
│ 第一卷：灵气复苏            │  │ 第一章：矿洞深处              │
│   第一章：矿洞深处      ←选中 │  │                              │
│   第二章：初次觉醒           │  │ 林烬睁开眼睛，后脑勺传来...    │
│ 第二卷：都市暗流            │  │                              │
│   第三章：霓虹地牢           │  │ 矿灯的光线在岩壁上晃动...      │
└────────────────────────────┘  └──────────────────────────────┘
```

**验证点**：
- [ ] TOC 展示所有已采纳的卷和章节
- [ ] 点击章节标题切换正文显示
- [ ] 未采纳的草稿不出现在 TOC 中
- [ ] 无内容时显示引导提示

**代码**：`ReadingMode.tsx:95-158` ✅（TOC sidebar + chapter content）

---

#### S2 — 空作品或无已采纳内容时

**作为作者**，我切到一个新作品或还没有采纳任何章节的作品。阅读模式展示空状态引导。

**验证点**：
- [ ] 显示"暂无已采纳的章节内容"
- [ ] 提示"返回工作台，在对话中生成并采纳草稿后，即可在此阅读"

**代码**：`ReadingMode.tsx:101-104`（TOC empty state）、`ReadingMode.tsx:133-135`（content empty state）✅

### 场景组 B：章节阅读

#### S3 — 章节正文渲染

**作为作者**，我选中一个章节，右侧展示正文内容。正文以场景+自然段落组织，不是原始 JSON 或代码块。

**验证点**：
- [ ] 章节标题渲染为标题样式
- [ ] 场景标题（scene.title）区分于章节标题
- [ ] 正文段落以 `<p>` 或换行分隔，不粘连
- [ ] 空场景显示"（该场景暂无已采纳正文）"

**代码**：`ReadingMode.tsx:138-154` ✅

### 场景组 C：投影状态

#### S4 — 底层设定变更后看到过期提示

**作为作者**，我在工作台修改了角色设定（如把林烬的武器从"剑"改成"刀"），再切回阅读模式时，看到投影过期提示。

```
┌──────────────────────────────────────────────┐
│ ⚠ 投影状态：已过期                            │
│ 底层设定已有变更，当前阅读的可能不是最新版本。   │
│                                    [刷新投影] │
└──────────────────────────────────────────────┘
```

**验证点**：
- [ ] `projectionStatus === "STALE"` 时显示黄色过期横幅
- [ ] "刷新投影"按钮可见且可点击
- [ ] 点击后返回工作台并触发 `refresh_projection`

**代码**：`ReadingMode.tsx:53-61` ✅

---

#### S5 — 投影重建中

**作为作者**，刷新投影后系统正在重建，我看到"重建中"提示，不需要我做任何操作。

**验证点**：
- [ ] `projectionStatus === "REBUILDING"` 时显示"投影状态：重建中"
- [ ] 不显示操作按钮（正在处理中）

**代码**：`ReadingMode.tsx:62-68` ✅

---

#### S6 — 投影重建失败

**作为作者**，重建失败了。我看到失败提示和"重试"按钮。

**验证点**：
- [ ] `projectionStatus === "FAILED"` 时显示"投影状态：重建失败"
- [ ] "重试"按钮触发 `retry_projection`

**代码**：`ReadingMode.tsx:70-77` ✅

---

### 场景组 D：模式切换

#### S7 — 从工作台切到阅读模式再切回

**作为作者**，我在工作台和阅读模式之间切换。切换后状态不丢失。

**验证点**：
- [ ] 工作台切到阅读模式：保留 `context.workId/workTitle`
- [ ] 阅读模式切回工作台：消息列表和输入框状态保留
- [ ] 切换不触发 WebSocket 重连

**代码**：`store.ts` `setMode` + `App.tsx` mode 切换 ✅
