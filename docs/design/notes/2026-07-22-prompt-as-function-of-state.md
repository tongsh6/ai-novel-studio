## 1. 定义转变

**旧隐含假设**：prompt 是需要打磨的话术文本，改 prompt=改措辞。

**定型**：每次模型调用的 prompt 是**数据现状的函数**：

```
prompt = f( 调用类型骨架,           -- 静态结构
            承重事实清单(manifest),  -- 该能力需要什么事实
            数据现状三态投影,        -- 在场/缺席/该建未建
            约束库+输出契约 )        -- 模型口径单一源
```

## 2. 三个维度

### 2.1 结构体系（静态）
- **Prompt 调用类型目录（SSOT）**：枚举全系统模型调用点（决策/创作/维护/评估类），
  每条登记目的、输入槽位、输出契约、约束集、探针、测试锚点耦合。
- **六段骨架**：①角色任务一句话 ②作者原文原样在场 ③机械事实层 ④行动目录直挂正文
  （T4 判例）⑤约束块靠近决策点 ⑥输出契约+结论→字段显式映射置尾（call2"登记"误判判例，
  修复 9b8e35e5）。
- **模型口径文案库**：模型侧共享字串集中定义（文案三层之外的第四层），与用户可见命名
  对齐（ui43 §5.0.1 脉络/审读先例）。
- **逐 prompt MBC 探针 + 变更纪律**：prompt 改动=行为改动，重大改动走 T4 式重放 A/B。
- 迁移策略：目录先立、骨架随真实病灶修复逐处迁移，不为体系化而重写。
- 落点：并入 `UA01-agentic-loop-prompt-hardening`（已登记未开工）作架构层。

### 2.2 状态感知（动态）——强制三件套 + 缺席行为学
- **判据剃刀**：缺了它模型会"自信地做错"→强制注入；缺了它模型会"知道该去查"→留探索面。
- **强制三件套**：层的在场保证（预算裁量、只可整条省略+OmissionNote）；位置/形式工程
  （决策点邻近、显式映射、目录直挂）；资格审查（只有经采纳边界的事实有资格被强制，
  防"强制垃圾"系统性带偏）。
- **缺席行为学（第三态）**：诚实缺席对系统是美德、对模型是真空——承重事实缺席时注入
  "缺席声明+行为守则"（例："本作品尚未确立主角档案：延续既有视角人物，不得另立主角"），
  不留真空给模型想象填补。
- **承重事实清单（per-capability manifest）**：每个创作能力声明必需/建议事实
  （prose：主角视角/阵容/卷弧目标/题材锚；outline：全书骨架/主角/卷弧…），
  是 08 要素模型在执行层的投影视图，也是六段骨架第③段的内容规格。

### 2.3 回路闭合（生成性）——prompt 驱动状态补全
- **设计负债规则族**（审读扩展）：对"该建未建"记账——已写 N 章无 PROTAGONIST→
  "主角未物化" finding；正文高频人物∉roster→"未登记角色接管候选"（R2 可行形态）；
  规划无全书骨架→骨架缺位。M3 跑实锤：地基事实真空时五脉空转（arc=0 主体，
  审读 50 章零报告），检测层必须能看见"缺失"本身。
- **设定盘点（修复回路执行端）**：AI 读数据现状（正文/摘要/空表）反向提炼"事实上的
  设定"，产 TENTATIVE 提案集，作者逐项采纳（Order53 流）。运行形态照抄
  `ledger_reconciliation_v1` 壳（readonly+恰一提案集）。命名切分：**审读管跑偏，
  盘点管缺失**。
- **默认设定三档边界**：行为守则型默认（可以，保守可逆）；工作假定型默认（待拍板，
  见 §3）；默认写入 canon（红线禁止，ADR-0010/0019——拦的是静默写入，
  AI 提案+作者点头不受限）。
- 闭环：负债 finding → 盘点提案 → 采纳入库 → 下次 prompt 的事实层更满 →
  系统随书的推进自己变聪明。

## 3. 已拍板（2026-07-22 用户裁决）

1. **工作假定层：全要素开放**——manifest 内所有承重要素（主角/视角、题材、卷弧、
   世界规则等）均可以"显式标注待确认假定"形态注入上下文。连带设计要求（因全要素
   开放而升级为硬性）：
   - 三防护对每条假定强制：显式标注（模型与作者双侧可见"这是假定"）、作者一键
     确认（转正采纳）/否决（作废）、审读跟踪假定寿命（挂 N 章未确认→finding 催办）；
   - **假定注册表**：假定是一等对象（非散落 prompt 文本）——集中存储、面板可见
     （待确认假定区）、有生命周期（提出/注入中/确认/否决）；
   - **假定间一致性**：同批假定不得互相矛盾（盘点产出时机械校验）；
   - **红线不变**：假定永不静默转正；确认前不进 canon、不进档案权威区、不参与
     采纳边界以内的任何写入。
2. **盘点触发形态：A+B+C 全落**——A 审读设计负债 finding 的处置动作（被动）、
   B 档案面板"发起设定盘点"（主动）、C 满 N 章无角色档案时对话流自动提议
   （onboarding；打扰节律：同一缺失只提一次、可关闭）。落地顺序 A+B 先行
   （既有范式复用）、C 随后（需打扰节律设计）。
