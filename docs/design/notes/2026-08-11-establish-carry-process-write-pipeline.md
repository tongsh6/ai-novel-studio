# 设立→携带→处理→写作方向:状态到正文的四层体系（讨论定型备忘）

> 状态：讨论备忘（不授权实现）。2026-08-11 刀④（信息账）拍板过程中用户定型：
> 「这是一个体系化工程,从伏笔设立以及预期,到每次进行写作时需要携带的信息
> （比如伏笔、比如世界规则、比如人物关系、比如剧情走向等等）,以及对这些携带
> 信息的处理（比如探索、比如推理等等）,然后才有写作方向。」
> 谱系：`2026-07-22-prompt-as-function-of-state.md` 的直接续篇——那篇定型
> 「prompt = f(状态)」;本篇定型 **f 本身分层：携带是选参,处理是求值,
> 写作方向是输出**。

## 1. 四层定义

| 层 | 含义 | 关键性质 |
|---|---|---|
| ① 设立层 | 事实与承诺的建立——**必须带预期/约束语义**,不只是内容 | 伏笔要带「打算何时收」;规则要带「约束什么」;没有预期的事实无法被下游推理 |
| ② 携带层 | 每次写作按写作坐标选取相关状态子集 | 选取是语义决策(相关性),不只是预算裁剪 |
| ③ 处理层 | 对携带信息的**探索**(按需查证)与**推理**(从状态推导本章使命) | 机械规则覆盖可判定部分;语义部分归模型,但模型结论须经作者裁决才落账 |
| ④ 写作方向 | ②③ 的输出,而非规划时一次性写死的静态文本 | 方向=f(当前状态),随状态流动 |

## 2. 现状盘点（2026-08-11）

- **①设立层——半建**。VS-00G（承重事实回路）/AU12（角色身份）/NEM04（场次槽）/
  刀④（信息与伏笔）逐把补齐;**系统性缺口=设立时不带预期**：伏笔无 planned_reveal
  （刀④首补）、世界规则无约束范围、关系无演化预期。
- **②携带层——建得最多但碎**。五条并行通道各有各的选取逻辑：CA01 阵容、CA02
  作品事实四组、progress_state（仅弧光）、执行简报（场级）、缺席/收官守则注入。
  无统一的「本次写作该携带什么」语义策略层（AssemblyPolicy 只管预算与省略）。
- **③处理层——真空最大**。探索半边只在作者提问场景跑（判断循环）,**正文直写
  路径零写前探索**;推理半边全部是机械投影（守则/简报/R 规则）,**模型级推理只有
  盘点与审读两个离线回路,均不在写作路径上**。「伏笔 X 预期本卷回收、本卷还剩
  两章 → 本章应推进回收线」这类从状态推导本章使命的一步,今天不存在。
- **④写作方向——形式上有,机制上静态**。plan_direction 九字段+场次槽+执行简报
  都是规划时写死;方向静态而状态流动,中间无推理层对齐——M3 题材漂移的结构性
  解释之一。

## 3. 本篇定型的判定原则（刀④伏笔分析为例证）

1. **预期归对象自己,不设全局常数**。伏笔「有的几章就收,有的贯穿全书」（用户
   原话）——悬空判定只对「有预期且超期」开火;无预期不发明阈值,机器不瞎猜。
2. **语义判断归模型,落账归作者**。回收判定机械匹配抓不住变体/隐喻回收,纯人工
   等于没有账;正解=模型分析产提议（盘点家族载体）+作者采纳才改账——处理层的
   模型半边必须以「提议→裁决」形态存在,与采纳边界哲学同构。
3. **携带按相关性,不按存量**。临近预期回收点的伏笔才进 writer prompt;贯穿
   全书型不逐条打扰。

## 4. 对后续刀的指向（不授权,供排刀输入）

- **写前推理层**是缺口最大的一步,候选下一大 slice：正文/规划调用前,对携带
  状态做一次处理（机械守则汇总 + 模型判断「本章使命」）,输出进入执行简报——
  让 ④ 从静态变成 f(当前状态)。
- **携带层统一**：五通道收敛为按写作坐标的单一选取策略（VS-00C AssemblyPolicy
  语义扩展）,是另一把独立的刀。
- 每把补设立层的刀,都必须同批回答「该对象的预期/约束语义是什么」——只落内容
  不落预期,处理层就永远没有输入（本篇第 1 原则的工程推论）。
