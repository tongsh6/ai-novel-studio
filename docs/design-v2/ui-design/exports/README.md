# UI Prototype Exports

> 状态：占位
>
> 角色：存放 `../novel-studio-v2.pen` 的静态导出物。

---

## 1. 目录规则

```text
exports/
  README.md
  png/
  pdf/
```

- `png/`：单屏或组件导出图。
- `pdf/`：评审用整包导出。

导出物不是 source of truth；source of truth 始终是：

```text
docs/design-v2/ui-design/novel-studio-v2.pen
```

---

## 2. 命名规则

导出文件名应包含文档编号与 screen 名：

```text
41-3-main-workbench.png
42-4-adoption-card-states.png
43-5-structure-panel-expanded.png
```
