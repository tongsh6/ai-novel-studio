# 02-v1-scope

## V1 目标

先验证以下闭环是否成立：

灵感输入 -> 作品立项 -> 章节细纲 -> 正文草稿 -> 阅读模式

## V1 的核心判断

V1 不是为了证明“AI 会写小说”，而是为了证明：

- 对话可以驱动创作动作
- 结构化内核可以维护作品状态
- 阅读模式可以形成闭环
- 最小对象集就足以支撑创作推进

---

## V1 必做

### 1. 单作品工作台
- 围绕一部作品持续创作
- 维持当前卷章与当前阶段

### 2. 对话式创作入口
支持自然语言触发：
- 作品立项
- 角色提炼
- 总纲
- 分卷
- 章节细纲
- 正文草稿
- 改写
- 切阅读

### 3. 结构化核心对象
V1 一等核心对象：
- Work
- Character
- Relationship
- WorldRule
- Outline
- Plotline
- Volume
- Chapter
- Event
- Foreshadow
- Draft
- DecisionLog
- ContinuityState

### 4. 正文版本
- 生成正文草稿
- 允许多版本改写
- 支持章节级查看与切换

### 5. 阅读模式
- 卷章目录
- 纯净正文视图
- 从阅读跳回创作

### 6. 决策记录
- 关键设定与结构变更需留痕
- 用户确认的事实必须固化

---

## V1 辅助对象

- Faction
- Location
- DocAsset
- PromptAsset

这些存在定义，但可以后置实现。

---

## V1 非目标

不做：
- 多人协作
- 权限系统
- 自动发布
- 创作 ERP 后台
- 图谱大屏
- 全自动整本书生成
- 复杂商业分析面板
- 复杂索引视图系统

---

## V1 页面形态

### 主工作台
- 对话流 + 结果卡片流
- 当前对象透视侧栏
- 当前上下文提示

### 正文工作态
- 正文为主
- 对话为辅助
- 可局部重写
- 可切阅读

### 阅读态
- 目录 + 正文
- 隐藏创作噪音

---

## V1 最小查询/动作集

### 查询
- 打开作品
- 打开当前卷
- 打开当前章
- 查看最新正文
- 查看最近决策

### 动作
- create_work_seed
- refine_character
- generate_outline
- create_volume_plan
- generate_chapter_outline
- draft_chapter
- revise_draft
- enter_read_mode

---

## V1 成功标准

1. 用户能从一句灵感走到立项底稿。
2. 用户能从章节目标走到细纲和正文草稿。
3. 用户能在同一工作台内完成创作态与阅读态切换。
4. 系统能稳定维护最小对象集的一致性。
