# 04-future-backlog

## 说明

本文件不是当前迭代范围，而是未来待启用设计池。  
目的不是催着现在做，而是防止长期设计失忆。

---

- Plotline 细粒度支线分析
- Event 参与关系变更追踪
- Foreshadow 生命周期看板

### 世界与连续性增强
- 更完整的 WorldRule 分层
- Location / Faction 完整启用
- 时间线冲突检查
- 知识边界 / 暴露边界可视化

### 正文工作增强
- 局部 diff
- 版本对比
- 风格偏差提示
- 上下文按动作智能召回

## 触发升级的条件

### SQLite -> PostgreSQL
出现以下情况再切：
- Web 化
- 多用户
- 服务端任务增多
- 更强 JSON 查询需求
- 更强审计与并发需求

### 辅助对象升级为一等对象
当某对象在多个动作中被频繁使用，且缺失会显著降低质量时，再晋升。
