# 协作模式设计：叙事指挥部 (Expert)

## 1. 目标
支持中大型作品的逻辑维护，提供极致的协作效率。

## 2. 界面布局
- **经典左中右三栏**：
    - **左：导航审计**。卷章树 + 角色状态（ContinuityState）实时变化流。
    - **中：核心工作区**。支持“细纲正文并排模式”或“版本对比模式”。
    - **右：指令控制台**。专业的对话入口，记录详细的 `DecisionLog`。

## 3. 核心交互流程
1. **多版本修订**：用户输入“重写结尾，要更悲剧”，系统在工作区并排显示 v1 与 v2，高亮差异。
2. **决策链路追溯**：点击任何一段正文，右侧自动定位到相关的 `decision_logs` 记录，解释该情节的设定初衷。
3. **状态同步**：正文编辑时，左侧的角色“伤势/持有物”状态根据 AI 实时分析自动更新。

## 4. 视觉风格
- 生产力工具风格（类似 Notion 或 VS Code）。
- 强调对比度，文字清晰度优先，减少多余动效。
