# 引导模式设计：灵感孵化器 (Beginner)

## 1. 目标
消除小白面对“白纸”的恐惧，将创作拆解为一系列轻松的对话。

## 2. 界面布局
- **单栏流式布局**：模仿微信交互，对话占满 80% 宽度。
- **动态动作条**：输入框上方出现“推荐动作”气泡（如：帮我起名、设计冲突）。
- **浮动里程碑**：侧边悬浮显示“创作进度条”，通过视觉反馈给予成就感。

## 3. 核心交互流程
1. **主动提问**：AI 检测到用户长时间沉默，主动根据 `ContinuityState` 提问：“刘浩现在拿到了宝剑，他第一个想试剑的人是谁？”
2. **卡片化实体**：用户输入的每一个重要设定（角色、伏笔），自动生成一张可点击预览的精美卡片。
3. **快速执行**：用户说“好，就按这个写”，UI 自动触发 `ADVANCE_PLOT`。

## 4. 视觉风格
- 圆角、高饱和度、友好且具有亲和力的色彩。
- 大量的微动效（如卡片生成时的缩放效果）。
