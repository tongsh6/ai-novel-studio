# 禅定模式设计：架构师控制台 (Master)

## 1. 目标
零干扰环境，仅在作者需要时提供深层逻辑支持。

## 2. 界面布局
- **书页视图**：全屏纯净阅读态，无明显 UI 元素。
- **隐形命令行**：`Cmd+K` 或 `Option+Space` 唤出极简搜索框。
- **注脚审计**：冲突点以“淡红色波浪线”出现在行间，只有鼠标悬浮才显示逻辑漏洞。

## 3. 核心交互流程
1. **深度查询**：通过命令行输入“/find @林恩 伏笔”，AI 瞬間在书页边缘标记出全书所有相关的伏笔落点。
2. **逻辑体检**：作者完成一个自然段后，AI 在后台静默运行，若发现违反 `DecisionLog` 的设定，在状态栏微弱提示。
3. **投影切换**：快速切换“全书全景投影”，将几百万字的作品压缩成一张逻辑图点，点击点位直接跳回对应正文。

## 4. 视觉风格
- 极简、低饱和度、甚至支持“全黑屏（墨水屏风格）”。
- 所有的 UI 都是“Ghost”形态，用完即消失。
