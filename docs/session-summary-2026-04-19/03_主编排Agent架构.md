# 主编排 Agent 架构

## 定位

主编排 Agent 不是“最会写正文的模型”，而是“小说项目总控系统”。

它的核心职责是：

- 管理完整小说要素
- 编排创作流程
- 调用执行模块
- 维护状态一致性
- 引入人工干预
- 积累经验并反哺后续生成

## 职责边界

### 应该做的事

1. 读取当前项目状态
2. 判断当前任务类型
3. 从小说要素库中抽取必要上下文
4. 选择执行模块并控制顺序
5. 做质量门禁
6. 触发人工审核节点
7. 回写状态与知识库
8. 更新经验库
9. 推进到下一任务

### 不应该做的事

- 不应该长期亲自写所有正文
- 不应该把整个知识库一次性塞进 prompt
- 不应该跳过校验直接把结果定为 canon
- 不应该让临时聊天结论自动升级为正式设定

## 人工干预模块

人工干预不是补丁，而是核心模块。

### 需要人工确认的节点

- 书籍定位
- 主角与反派重大设定
- 卷纲定稿
- 关键章节细纲
- 重大人物命运
- 大高潮方向
- 结局方向

### 人工干预的作用

- 防止系统自信偏航
- 保持作者主导权
- 明确 canon 批准点
- 管理高风险改动

## 经验积累模块

经验积累模块负责把历史创作过程转化为后续可复用规则。

### 经验来源

- 作者修改记录
- 被接受版本
- 被否决版本
- 章节复盘
- 高风险错误记录
- 已验证有效的 prompt 模式

### 经验模块应沉淀的内容

- 作者偏好画像
- 本书特有写法
- 高频错误清单
- 节奏经验
- 爽点经验
- 情感推进经验

## 大闭环

```text
小说要素建模
-> 编排生成
-> 质量检查
-> 人工干预
-> 定稿
-> 状态回写
-> 经验提炼
-> 下一轮生成更稳
```

## 小闭环

### 人物闭环

`人物创建 -> 登场与事件参与 -> 状态变化 -> 回写 -> 后续继续引用`

### 世界观闭环

`设定 -> 进入剧情 -> 状态变化 -> 回写 -> 后续可检索`

### 伏笔闭环

`规划 -> 埋设 -> 延迟 -> 回收 -> 更新状态 -> 后续影响`

### 爽点闭环

`卷级规划 -> 章级落地 -> 正文实现 -> 检查成立性 -> 回写后果`

### 节奏闭环

`卷级节奏 -> 章级节奏 -> 正文表现 -> 写后校验 -> 调整下一章`

### 经验闭环

`生成 -> 人工修改/接受/拒绝 -> 记录差异 -> 提炼经验 -> 反哺下一轮`
