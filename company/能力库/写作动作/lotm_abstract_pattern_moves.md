# 公司级候选能力包：《诡秘之主》抽象模式转写作动作 v1

- 状态：approved/company-capabilities
- 日期：2026-05-12
- 类型：写作动作库候选扩展
- 来源：本地《诡秘之主》章节结构学习
- 注意：本能力包不含原文，不含原句，不含专有设定，只提供可复用写作动作。

## OPEN-01 短段异常入场

- 所属模块：开篇 / 悬念 / 节奏
- 适用场景：章节开头、场景开头、危机转入、诡异事件转入。
- 读者效果：先产生问题，再等待解释。
- 输入要求：本段异常、视角人物第一反应、不能揭示的答案。
- 执行动作：用一到三句短段呈现状态、动作、声音或问题；不解释背景。
- 禁止动作：第一段讲世界观、历史、规则原理或人物完整心理。
- 段落卡写法：`OPEN-01 + SUS-02 + POV-01`
- 验收标准：读者读完第一段能说出一个具体疑问。

## ANCH-01 日常锚点托底

- 所属模块：场景 / 信息植入
- 适用场景：神秘规则、仪式、异象、超凡物品、宗教组织、复杂设定。
- 读者效果：神秘内容有现实重量，人物不是漂在设定里。
- 输入要求：两个以上日常锚点，至少一个和人物利益或身体有关。
- 执行动作：用钱、食物、工具、门窗、灯火、衣物、伤痛、路程、手续等承载设定影响。
- 禁止动作：连续堆术语，不让设定影响具体生活。
- 段落卡写法：`ANCH-01 + SCN-05 + INF-06`
- 验收标准：删除神秘名词后，段落仍然有可见动作和现实压力。

## RULE-01 现象先于规则

- 所属模块：规则链 / 信息植入 / 悬念
- 适用场景：能力首次出现、规则升级、禁忌触发、仪式失败。
- 读者效果：读者跟着人物一起理解规则，而不是听作者讲课。
- 输入要求：现象、常识解释、反证、局部判断、代价。
- 执行动作：先写异常结果，再写人物用有限证据推断。
- 禁止动作：先给完整规则表，再让人物执行。
- 段落卡写法：`RULE-01 + SUS-01 + POV-04`
- 验收标准：本段只解释到“足够行动”，不解释到“完全懂了”。

## INV-01 调查验证回路

- 所属模块：调查 / 证据阶梯
- 适用场景：案件、诡异事件、人物身份、组织阴谋、资源寻找。
- 读者效果：主角显得会思考，但不是上帝视角。
- 输入要求：问题、线索、验证办法、风险、验证后的新未知。
- 执行动作：让主角用低成本办法验证一个小判断，并承担风险。
- 禁止动作：主角无证据直接猜中全部真相。
- 段落卡写法：`INV-01 + INF-03 + POV-04`
- 验收标准：证据状态在段落或场景内发生变化。

## DLG-09 交易式对话

- 所属模块：对话 / 信息植入
- 适用场景：聚会、委托、审问、谈判、交换情报、结盟。
- 读者效果：每句话都有筹码，不是设定说明。
- 输入要求：说话人的表面目的、隐藏目的、筹码、底线。
- 执行动作：让对话围绕报酬、安全、身份、承诺、知识差或风险交换展开。
- 禁止动作：人物无代价、无保留地把信息说完。
- 段落卡写法：`DLG-09 + DLG-01 + DLG-07`
- 验收标准：对话结束时，至少有一方获得、失去或误判一个筹码。

## HUB-01 固定信息枢纽

- 所属模块：结构 / 对话 / 长线伏笔
- 适用场景：固定聚会、固定交易点、固定联系人、固定仪式、定期汇报。
- 读者效果：每次回到固定场景，都期待长期问题更新。
- 输入要求：本次议题、长期账本、角色关系变化、隐藏风险。
- 执行动作：保留固定流程的秩序感，同时让一个长期问题被推进。
- 禁止动作：每次固定场景只重复格式，不更新信息。
- 段落卡写法：`HUB-01 + INF-05 + DLG-09`
- 验收标准：本场结束后，长期信息账本至少多一条变化。

## MASK-01 身份面具错位

- 所属模块：人物 / 悬念 / 对话
- 适用场景：化名、卧底、阶层伪装、宗教身份、职业身份、敌我不明。
- 读者效果：人物说的话看似成立，但身份压力在底下发紧。
- 输入要求：公开身份、隐藏身份、对方误判、不能说破的知识。
- 执行动作：通过称呼、礼节、话语边界、站位、沉默和误判表现身份压力。
- 禁止动作：旁白直接解释“他其实在伪装”。
- 段落卡写法：`MASK-01 + ACT-08 + DLG-03`
- 验收标准：读者能感觉身份不稳，但没有被直接告知全部答案。

## RELAX-01 高压轻松拍

- 所属模块：节奏 / 人物反应
- 适用场景：连续高压后的喘息、诡异规则中的生活麻烦、危险前的准备。
- 读者效果：角色更像活人，压力更有层次。
- 输入要求：当前压力、一个生活化麻烦、人物习惯性反应。
- 执行动作：在不解除危机的前提下加入一拍轻微自嘲、利益计算或日常尴尬。
- 禁止动作：破坏主情绪，变成段子。
- 段落卡写法：`RELAX-01 + INR-03 + RHY-04`
- 验收标准：读者获得短暂松弛，但下一段压力仍能接住。

## END-01 小兑现接大未知

- 所属模块：结尾 / 钩子
- 适用场景：章节结尾、场景结尾、调查阶段结尾、战斗后。
- 读者效果：有满足感，也有继续读的理由。
- 输入要求：本章小兑现、新物件或新限制、新问题、下一章期待对象。
- 执行动作：解决眼前问题，同时抛出与之相关的更高层未知。
- 禁止动作：只吊不兑现，或只总结“更大的危机来了”。
- 段落卡写法：`END-01 + SUS-05 + RHY-05`
- 验收标准：结尾同时回答一个问题，并制造一个更具体的新问题。

## DENS-01 短段动作链

- 所属模块：段落密度 / 节奏
- 适用场景：连载章节正文、追踪、问答、准备、调查、战斗前后。
- 读者效果：阅读轻快，推进细密。
- 输入要求：本场动作链、每段小变化、段尾承接方式。
- 执行动作：每段只完成一个动作、反应、判断、信息变化或转场压力。
- 禁止动作：一段同时解释背景、心理、设定和结果。
- 段落卡写法：`DENS-01 + RHY-01 + AAI-07`
- 验收标准：段落之间是动作链，不是摘要链。

## 合同调用建议

生成段落导演式合同时，若章节属于诡秘、调查、宗教、超凡、政治交易、身份伪装或固定聚会结构，优先检查是否需要调用：

- `OPEN-01`
- `ANCH-01`
- `RULE-01`
- `INV-01`
- `DLG-09`
- `HUB-01`
- `MASK-01`
- `RELAX-01`
- `END-01`
- `DENS-01`

每章不必全用。建议主模块 2 到 4 个，辅助模块 2 到 5 个。
