# 商业开篇审核经验

## 1. 用途

这份资料给审核部和写作部共用，用来判断“第一章写得像不像能留住读者的网文开篇”。

它不是题材设定文档，而是审稿时的执行经验。

## 2. 第一章最低要求

审核第一章时，至少要看清五件事：

- 主角的特殊性有没有亮出来。
- 主角是不是只在挨打，还是已经开始反向利用漏洞。
- 有没有具体情绪对象，而不是抽象“家人”“仇恨”。
- 世界规则有没有真的咬到人。
- 章尾是不是事件钩，而不只是姿态钩。

## 3. 商业开篇最常见三种失败

### 3.1 只有氛围，没有追读钩

文笔稳，设定也不差，但读者不知道下一章必须看什么。

### 3.2 只有压迫，没有回报

整章都在虐主，却没有一点小反击、小识破、小漏洞、小进账。

### 3.3 只有后台概念，没有前台动作

作者知道设定很复杂，但正文里读者只看见名词，没有看见动作、代价和现场后果。

## 4. 审核提问顺序

审核第一章时固定这样问：

1. 这章最强的意象是什么？
2. 这个意象有没有落到具体动作？
3. 主角此刻最想要什么？
4. 他有没有为此做出主动判断？
5. 规则有没有产生现场反馈？
6. 读者下一章最想追什么？

## 5. 结尾判断

### 弱结尾

- 他还在反抗。
- 他握紧了武器。
- 他没有认输。

这类结尾有态度，但追读拉力弱。

### 强结尾

- 规则变了。
- 漏洞出现了。
- 某个不该发生的后果发生了。
- 主角发现了一个必须马上利用的新缝隙。

## 6. 审核部输出格式

以后审强开篇，默认给出：

1. 总判断
2. 最强卖点
3. 最大短板
4. 三条必须改的硬项
5. 章尾是否过关
6. 是否允许继续写下一章

## 7. 与网站的关系

这份资料应该在公司总览和审核部执行上下文里都能被直接读到。

它是当前有效方法，不再经过提案区流转。
