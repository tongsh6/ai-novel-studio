# 公司级写法候选：悬念前置与期待吊钩合同规则 v1

## 一、使用目的

以后主 agent 生成章节合同时，不能只写剧情大纲，还要把“这一章该怎么写”写清楚。外部正文模型不了解前后文，合同必须告诉它本章要采用哪一种写法模块、如何开篇、如何吊期待、如何释放信息、如何压住结尾钩子。

本规则重点解决三个问题：

- 合同只交代“发生什么”，没有交代“怎么让读者想看下去”。
- 正文容易把设定一次性讲完，缺少悬念前置和延迟满足。
- 主角推理、诡异规则、世界背景、爽点兑现混在一起，导致节奏发散。

## 二、核心观察

优质诡秘悬疑型网文的章节，通常不是先讲世界观，而是先给读者一个可感知的异常。读者先看见痛、物、声音、错位感、危险物件或不合常理的场面，再跟着主角一步步找解释。

这种写法的关键不是“神秘名词多”，而是四个动作：

- 先让读者发现哪里不对。
- 立刻给一个生活化锚点，让场景可信。
- 让主角通过有限证据做判断。
- 当前问题刚解决，结尾出现更尖的新问题。

合同必须把这四个动作拆细，否则外部模型会自然滑向设定说明或平铺直叙。

## 三、合同可调用写法模块

### 1. 悬念前置三件套

适用：开篇章、危机章、诡异章、转折章。

合同需要明确：

- 第一屏异常：300 字内出现一个读者不能忽视的问题，例如疼痛、尸体、怪声、违和物件、无法解释的仪式、主角处境反常。
- 具体锚点：异常旁边必须有可触摸的日常细节，例如钱、食物、工具、伤口、衣服、门锁、锅、账本、气味。
- 未答问题：读者必须立刻产生一个清晰疑问，例如“他为什么在这里”“这东西为什么会动”“谁在撒谎”“这条规则会害死谁”。

禁忌：

- 不要先写大陆史。
- 不要先解释力量体系。
- 不要用抽象形容词替代场景。
- 不要让悬念只是一个空泛名词。

### 2. 日常锚点托底

适用：奇幻、诡异、神秘设定较重的章节。

超凡越离奇，越要用日常细节压住可信度。合同要要求正文写出至少两个日常锚点：

- 生计锚点：钱、粮、税、债、赏金、租金、工钱、物价。
- 身体锚点：疼、饿、冷、渴、困、伤口、汗、气味。
- 工具锚点：钥匙、锤子、锅、灯、绳、车板、纸、墨、门栓。
- 程序锚点：登记、巡逻、审判、祷告、报名字、分粮、值夜。

日常锚点的作用，是让读者相信主角不是漂在设定里，而是站在一个能摸到的世界里。

### 3. 证据阶梯

适用：调查章、诡异规则章、金手指初醒章、世界真相章。

合同必须写出本章证据释放顺序：

- 第一层：一个小异常，主角可以先用常识解释。
- 第二层：出现反证，常识解释开始松动。
- 第三层：主角找到有限证据，只能得出局部判断。
- 第四层：主角根据局部判断行动，而不是等作者解释完。
- 第五层：行动验证一部分判断，同时暴露新的未知。

这条规则能防止金手指直接喂答案，也能防止主角像上帝一样一眼看穿真相。

### 4. 期待钩与延迟满足

适用：每一章。

合同要提前指定本章的“期待对象”。期待对象必须具体，不能只是“读者想看后续”。

常见期待对象：

- 主角能不能逃出去。
- 某个东西到底是什么。
- 某个人会不会背叛。
- 主角能否拿到第一顿饭、第一件武器、第一条线索。
- 敌人会不会发现他。
- 金手指会付出什么代价。

写法要求：

- 期待对象要尽早露面。
- 中段必须设置两到三个障碍。
- 章内给一部分兑现，让读者有爽感。
- 结尾把期待升级成更大的问题。

### 5. 信息差三层

适用：悬疑、政治、宗教、潜入、反转章节。

合同要区分三层信息：

- 主角此刻知道什么。
- 读者通过细节能多猜到什么。
- 作者暂时藏住什么。

外部模型必须严格按第三人称有限视角写，不能把隐藏信息提前说破。读者可以比主角多一点不安，但不能直接拿到答案。

### 6. 近视角推理链

适用：主角需要显聪明但不能像攻略器的章节。

推理链不要写成总结式旁白，而要贴着主角的动作和压力走：

- 观察到什么。
- 第一反应是什么。
- 哪个细节让他否定第一反应。
- 他能承担哪些代价。
- 他选择哪条风险最小或收益最大的路。
- 选择后立刻承担后果。

主角可以误判。误判必须合理，而且要推动读者相信他是在临场求生，不是在替作者宣读答案。

### 7. 行动计划与程序压力

适用：潜入、逃亡、审判、围城、抢粮、仪式、交易。

合同必须写出本章行动计划：

- 目标是什么。
- 时间窗口有多短。
- 有几个检查点。
- 失败后最坏结果是什么。
- 主角有哪些资源。
- 哪个环节最容易出事。

程序压力比抽象危险更能吊住读者。比如巡逻间隔、钟声、审判流程、火把距离、锅快翻、天快黑，都比“危险逼近”更好用。

### 8. 规则链

适用：金手指、诡异、神术、界碑、圣兵、源力体系。

合同要规定正文只能通过现象展示规则：

- 规则先表现为结果，不先解释原理。
- 每次使用都要有代价、限制或误差。
- 规则要能被主角部分利用，也能反过来伤害主角。
- 同一规则在后文要可复用，不能一次性工具化。

示例方向：七烬魂镜不能给路线和任务，它只能让卡西安看见残魂裂痕、神谕空洞、死路回声，并让他付出疼痛、失神、幻听等代价。

### 9. 对话交易与试探

适用：多人对话、审判、谈判、同盟、敌我初见。

合同不能只写“他们交流信息”。每场对话要明确：

- 表面目的：这句话表面上在问什么、求什么、骂什么。
- 隐藏目的：说话人真正想测试什么、遮掩什么、换取什么。
- 信息变化：这句对话让主角获得、失去或误判了什么。
- 情绪变化：这句对话让场面更紧、更松、更怒，还是更危险。

人物说话要带身份差异。教会说罪与救赎，流民说粮和活路，工匠说材料和活，贵族说体面和合法性。

### 10. 结尾反钩

适用：每一章。

一章可以解决当前小问题，但结尾必须打开更大问题。结尾反钩优先选择以下类型：

- 新矛盾：刚逃出火刑，追捕钟声响起。
- 新证据：界碑回应名字，说明这里有旧债。
- 新人登场：门后出现不该出现的人。
- 新规则：金手指救了人，也让主角听见死者哭声。
- 新代价：赢了这一局，粮却少了一半。
- 新期待：拿到第一顿饭，读者开始等第一面墙、第一场战斗或第一笔交易。

不要用空泛的“更大的风暴即将来临”。要让读者看见风暴的一片乌云。

## 四、合同新增结构模板

以后章节合同建议新增一节“本章写法策略”，放在工作边界后、正式剧情结构前。

该节至少包含：

- 主写法模块：从悬念前置、证据阶梯、期待吊钩、行动计划、规则链、建设爽点、对话试探、结尾反钩中选择二到四个。
- 开篇钩类型：感官异常、身份伤口、危险倒计时、神秘物、反常处境、对话冲突、收益诱惑。
- 本章期待对象：读者这一章最想等什么。
- 信息释放顺序：本章必须按什么顺序放信息。
- 证据阶梯：异常、反证、局部判断、行动验证、新未知。
- 场景级钩子：每个场景结尾用什么小问题把读者拖进下一场。
- 结尾反钩：本章解决什么，又抛出什么。
- 禁用写法：本章最容易写崩的方式。

## 五、写法模块选择表

| 章节类型 | 优先模块 | 合同必须强调 |
| --- | --- | --- |
| 开篇危机 | 悬念前置、身份伤口、期待吊钩、结尾反钩 | 第一屏必须有处境和情绪，不能先讲设定 |
| 逃亡危机 | 行动计划、程序压力、规则链、信息差 | 时间窗口、追兵距离、身体代价、路线未知 |
| 诡异事件 | 日常锚点、证据阶梯、规则链、近视角推理 | 先现象后解释，规则有限，代价明确 |
| 领地建设 | 具体抓手、资源缺口、建设爽点、群体冲突 | 一顿饭、一口井、一面墙、一条规矩要可见 |
| 调查解密 | 证据阶梯、信息差、对话试探、结尾反钩 | 不一次性揭露真相，阶段性验证 |
| 潜入行动 | 行动计划、程序压力、近视角推理、反钩 | 检查点、伪装、意外、退出路线 |
| 宗教审判 | 对话试探、身份压迫、情绪曲线、制度展示 | 残酷要被包装成神圣，主角情绪必须站稳 |
| 政治谈判 | 隐藏目的、筹码交换、信息差、期待吊钩 | 每个人有利益，不能为剧情服务而降智 |
| 战斗章节 | 目标限制、环境利用、代价、爽点兑现 | 主角不能无脑碾压，胜利来自判断和执行 |

## 六、合同验收清单

生成合同时，主 agent 自检：

- 第一屏有没有明确异常或冲突？
- 主角情绪是否比世界观更早出现？
- 读者这一章等的东西是否具体？
- 有没有至少两个日常锚点？
- 信息是否按证据阶梯释放，而不是设定倾倒？
- 金手指或超凡规则是否有代价和限制？
- 每个主要场景末尾是否有小钩子？
- 对话是否包含试探、交换或冲突？
- 本章是否有部分兑现，而不是只吊不爽？
- 结尾是否解决当前小问题并打开更大的问题？
